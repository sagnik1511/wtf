## Overview

The agent inspector previously displayed action scores as numerical rows and
observations as a raw array. It now shows spatial inputs and action predictions
visually, while preserving timestamps, raw values and bounded replay memory.

## Changes

- Toggleable board highlight for the selected agent's current legal sight area,
  including occlusion and water-limited directional extension. Full-circle sight
  follows the simulation; heading, elevation and other animals do not occlude.
- Radar for sampled top-k food/prey/predator positions, sample heading, presence
  counts, health/energy gauges and blocked directions. Terrain and mating inputs
  have expandable summaries; version-3 mate indicators remain separate.
- Action probability bars for policies and signed Q-return bars for Q learners.
  Highest predicted scores and masked actions are labelled without claiming a
  sampled action or prediction accuracy.
- Expandable prediction-sample chart keeps at most 64 detached score vectors for
  one selected agent. It carries across forward chunk changes, filters future
  points on backward seek and resets by recording/run/agent. Gaps stay unfilled;
  inspection does not preload old chunks or retain their frames/features.
- Graph subtrees are reused between diagnostic samples. Static sight geometry is
  cached for one observer position/range/map/obstacle set; moving animals do not
  block sight, so they require no geometry invalidation. Dynamic targets still
  come from actual recorded diagnostic samples. Cache lifetime is viewer-local.
- Body/training fields and raw features remain in disclosures; expanded sections
  persist across sample updates. Current-frame geometry and sampled brain inputs
  are explicitly distinguished.

## Compatibility and migration

Refresh the browser page. No backend, training, configuration, observation layout
or replay codec changes. Existing diagnostic-bearing recordings are sufficient;
missing/unknown inputs remain explicit rather than guessed. No model weights,
new packages, screen recording or result conversion are added. The viewer still
retains one decoded playback chunk plus the small selected-agent score history.

## Validation

- All 63 viewer JavaScript tests passed. Thirteen new inspector tests cover observation versions/k, padding, legacy/missing values, signed Q values,
  masks, histories/seeks, disclosure persistence and zero-value scales.
- Sight matches Python World visibility on 48 cases across eight presets, both
  species roles, boundaries, walls and wet/dry terrain.
- Recording and directional-water suites: 17 Python tests passed.
- Browser preview verified an existing 68-input replay's radar, action probability
  bars and current sight shading. No screen recording was made.

## Rollout and rollback notes

Committed in `91697aa` on 2026-11-19. The preview server is separate
from training. Reverting viewer files restores the prior inspector and needs no
replay migration. Existing backend sessions need no restart for file readers;
reload the browser to fetch the updated HTML/JavaScript/CSS.
