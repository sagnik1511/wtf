## Behavior and configuration

Optional per-brain `movement_history_steps` retains selected personal sightings,
matching internal identities across target-slot changes. Hidden targets retain
last-seen estimates with fading confidence; unobserved positions and hidden death
never update those memories. Newborns acquire new histories rather than inherit
their parents' sensory state.

Root `scent_trails` enables merged cell/species/sex deposit times and configurable
linear fading. Per-brain `scent_observation` chooses ordered species channels,
sex separation and automatic dry-path sensing radius. All local sectors are
reported rather than selecting one animal to follow. Sealed obstacles and water
stop ground sensing. No individual identity, live target location, consent or
new sniff action is supplied by the scent field.

All nine algorithms receive the appended inputs. Neither feature forces hunting,
mating or contests, and proximal physical/consent gates remain unchanged.
`tracking.json` demonstrates both features without editing existing presets.

The selected-agent inspector draws sampled personal movement and velocity
estimates, plus a blended heatmap or legacy named species/sex scent grids. Live CSS and standalone
source-rendered documentation specimens support light/dark palettes. Direct chart
navigation avoids hiding the sensory section below the sidebar fold. Selecting
an animal also enables its recorded visual-track overlay on the main board, using simple connected sightings without projected arrows;
scent patterns stay in the inspector. The viewer heatmap accumulates all-animal movement arrivals only through the
current replay frame. Forward steps and local rewinds update one reusable
unsigned-integer grid from the loaded chunk. Large jumps rebuild a prefix by
streaming saved chunks through the requested frame on the server, rather than
retaining per-frame snapshots or decoding an entire run in the browser. The
shared movement counter preserves full-run CLI analysis while viewer behavior
responses omit their unused full-run grid. A numeric key and an increasing-
brightness dark palette make the time-bounded heatmap easier to interpret.
Existing saved recordings need no regeneration after restarting an older server.
The end-of-recording notice uses matching theme panel/text colors, preserving
contrast in light and dark modes independently of board sunlight. The wider
label audit adds semantic event/error/notice palettes, readable primary and
disabled controls, neutral legend text, and contrasting canvas event badges.
Inspector tracking paragraphs are replaced by compact headings and marker hover
details, preserving space for the diagrams.

Blended scent is an explicit new input mode: one nine-sector anonymous field
and one inspector heatmap across all species/sexes. The tracking preset selects
this mode. Old omitted-mode configurations retain their canonical separated
signatures, observations and grids. Overlapping group traces sum per cell with
a cap of one before sector maxima; both modes share the existing sparse field,
checkpoint state and sampled replay vectors. No second map is stored.

## Storage and compatibility

Per-observer sighting windows and sparse merged integer deposits are bounded;
ordered expiration and a bounded shared channel-plan cache avoid full-map decay
and repeated channel setup. Exact checkpoints add version-1 sensory state and
GRPO trials own detached copies. Replays reuse sampled input vectors in existing
binary chunks: no separate trajectory archive or per-frame scent map is stored.
Enabled senses increase model inputs and diagnostic/training-buffer costs.

Existing configurations keep both senses off and retain legacy model signatures
and checkpoint/replay formats. Enabled models require matching history and scent
contracts; old weights need a fresh compatible model. Older runtimes cannot
resume enabled sensory checkpoints. Refresh the viewer for new modules; keep
old/new source or wheel files together. Package version remains `0.0.2.0` and
this pending rollout does not publish a distribution.

## Rollback

Disable both senses on fresh configurations to retain the previous input layout.
Do not strip sensory state from an enabled exact-resume checkpoint or treat
incompatible old weights as a warm start. Preserve existing artifacts when
reverting; recordings remain read-only, with legacy inspectors unable to explain
the new optional inputs.
