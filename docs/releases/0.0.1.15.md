## Overview

Playback documentation explained encoding and data flow but needed structural
views of the artifacts and their contents. A dedicated guide now links actual
schemas to connected, nested block diagrams and a verified delta example.

## Changes

- Experiment artifact diagram distinguishes directory contents from file
  references, including playback, reports, exact checkpoints and champion pools.
- Binary diagram shows prefix, length-prefixed header/keyframe/delta/footer
  blocks and a nested entity table with physical field columns.
- Delta diagram shows before/after field cells, highlighted mask bits, a stored
  update tuple and the reconstructed entity. Values support the structure.
- The guide documents manifest entries, frame/entity fields, delta operations
  and reading/memory boundaries. Existing guides and catalogs link it.
- Clarified that `WTFB` plus version `0x01` totals five prefix bytes.

- Model-weight block diagram adds shared references, the one-record model blob
  and PPO layer-array shapes, with a champion/checkpoint comparison in the guide.

## Compatibility and migration

Documentation and original SVG assets only. No runtime or file-format changes,
result conversion, dependencies, recording or training required. SVGs themselves
are directly editable maintained sources; raster review previews remain ignored.

## Validation

- Checked file names, manifest/frame/event fields and delta field order against
  recorder, world, codec and viewer sources.
- Verified mask 20 and exact two-frame reconstruction using the current codec.
- Round-tripped header/keyframe/delta/footer through binary records and XZ;
  verified a four-row entity table uses tag 11 and decodes exactly.
- Verified model array shapes, one-blob reuse, SHA-256, exact readback and
  fresh-controller weight loading without training.
- Reviewed raster previews for all four block diagrams. Checked SVG structure,
  local Markdown links/anchors, release navigation and whitespace.
- No simulation suite or performance benchmark needed for this docs-only change.
