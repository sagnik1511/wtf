## Result

Stores the conversation's physics examples in tracked `docs/assets/physics/`:
ten static SVGs, an editable interactive fragment and a portable standalone HTML
export. Cases cover the actual founder layout, sight before/after water credit,
dry rays, walls, high ground, species sight differences, the actual valley gate,
walking/swimming and weak entry, fractional current/dry landing, drowning,
allowed/blocked/downhill slopes and mutual nearby/missing-choice/out-of-range
birth. Interactive controls retain both species and intermediate steps.

[Physics illustrated](../physics.md) embeds every static case and explains
physics versus observation encoding. README, geography, project context and the
asset index link the guide. GitHub renders SVGs; open/download the HTML locally
for controls. Unused optional CDN imports were removed, so the HTML loads no
network scripts and requires neither ChatGPT nor a running simulation.

`work/build_physics_docs.py` regenerates controlled World.step snapshots, figures
and the embedded HTML data. `work/check_physics_docs.cjs` checks control logic.
These utilities need only existing Python/Node installations, not a new package.
No models, checkpoints, experiment replays or source video were added. Physics,
training, configuration defaults and viewer behavior are unchanged by this rollout.

## Verification

- All ten SVGs parse as XML. Physics outcomes and captions checked against
  controlled simulation snapshots; repeated generation is deterministic.
- Node smoke checks cover sight toggles, actual terrain, blocked walking, swimming,
  cliffs and mutual/in-range birth. The original interactive ray implementation
  matched Python on 1,916 cases.
- Standalone source and export remain synchronized, with no external script loads
  or personal filesystem paths. Relative guide/asset/release links and diff
  whitespace checked. The complete collection is under 600 KB.
- Browser screenshot inspection could not be completed in this environment;
  SVG geometry and interaction logic were checked offline. No broad runtime
  test rerun or new training experiment was required for documentation assets.

## Adoption and rollback

Read the guide or open `docs/assets/physics/explorer.html`. GitHub HTML-source
view is not the interactive explorer; the guide includes optional local serving
instructions. Generated static snapshots reflect the configuration at generation
time; regenerate and review captions after changing physics/settings.
Remove the gallery/tools/links to roll back documentation only. Existing results
and runtime formats are unaffected. No commits, tags or package versions created.
