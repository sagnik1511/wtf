## Behavior changes

- Adds `move_backward`, `strafe_left` and `strafe_right`: one-cell walking relative
  to heading, without turning. Ordinary collision, contention, slope, effort and
  failed-action feedback apply. Walking cannot substitute for swimming.
- Escape actions cancel mating intent, including blocked attempts. Movement
  still resolves before attacks; no automatic avoidance or invulnerability is added.
- Observation version 4 appends own consent fraction, the nearest visible mate's
  consent fraction and a local eligible consenting-mate opportunity flag.
  Visibility and physical mating gates remain intact; no future choices or
  hidden agents are exposed. Reads consume no RNG or recurrent state.
- Adds inspector labels and action predictions for these inputs/actions. Walking
  analysis reconstructs all relative directions, effort and failures.
- Extends native flat-metabolism handling with the `escape_movement` capability
  marker. Older binaries use Python metabolism when the new actions occur.

## Compatibility

Version-4 inputs total `45 + 12 * (k - 1)`. Versions 1–3 preserve their contracts.
Action order, observation version and top-k remain part of model compatibility;
start with compatible models or fresh weights after changing them. New replay
movement labels require updated readers; legacy recordings remain supported.
Rebuild optional native kernels after updating the native source.

Configuration files expose the added actions and consent inputs without changing
physical mating eligibility. Populations, health, radii and policy settings are
JSON parameters, not ecological guarantees attached to this release.

## Validation

Regression checks cover relative directions, ordinary and failed effort,
movement/combat ordering, occupancy/contention, water and cliffs, native/Python
parity, stale-binary fallback, consent visibility/cancellation, model signatures,
checkpoint continuation and binary replay. Inspector checks cover labels and
input dimensions. Repository source formatters and their check modes passed.

## Adoption and rollback

Use the matching implementation for active checkpoints and new replay labels.
Restore an earlier action/observation contract only with compatible saved models
or fresh initialization. Changing an available action does not establish that
policies use it effectively; evaluate behavior separately from feature tests.
