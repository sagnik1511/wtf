## Overview

A brain can receive general species/action knowledge and current-context
consequences simultaneously. `consequence_scope: "both"` concatenates two
separate 48-value blocks, general first. Each has independent confidence, so
unknown context does not erase general evidence. Existing state inputs let the
network learn relevance without a hard-coded selector or numerical blending.

## Changes and compatibility

The existing `context` default and `species_action` modes remain configurable
with their 48-value layouts. Combined mode uses 96 consequence values and a
distinct saved-model signature. It requires fresh/matching model weights;
legacy models/checkpoints keep their original scopes and input widths.

Evidence is still collected once from real attempted actions. All modes query
the same published tables, obey existing continuous/episode timing and preserve
private policies and execution constraints. Physical consequence exports remain
compatible across scopes when their existing physical/horizon contracts match.
The current local seaside DQN scent/day-night config opts into combined mode;
maintained presets retain their selected modes.

Both inspector and species dashboard show general/context chart groups and
confidence separately. Cumulative history preserves both sources through seek
and resets, reusing SVG nodes. The updated controlled visual shows all three
witness/general/context groups in both destinations.

Combined input vectors enlarge first-layer weights, buffers and recorded
samples. No new persistent evidence table, top-level replay field or checkpoint
version is introduced; this feature does not claim a storage reduction.

## Fixes and optimizations

Independent review found no actionable defects requiring an additional fix.
Regression checks verify that combined observations concatenate general then
context estimates exactly, retain independent confidence and conflicting rates,
and preserve masked-action knowledge without collecting evidence twice. All
14 learners retain exact checkpoint continuation, independent inheritance and
explicit model/XAI compatibility for the wider layout. Viewer checks preserve
both sources through averaging, rewinds and in-place chart updates.

General prediction caches retain immutable rate tuples and return detached lists
sharing immutable floats. This avoids repeated rate calculations while preserving
per-species invalidation, staged-publication isolation and persistence boundaries.
The wider input vector still increases model and recording size; no measured
speed or peak-memory improvement is claimed.

Species playback means also reuse validated member/row identities between
samples. A 70-animal/1,600-frame local probe reduced mean reconstructions from
3,200 to 64 and median aggregation from 116.89 to 92.18 ms, with matching
per-frame cumulative view hashes. This is an aggregation-only measurement,
not a whole-viewer or RAM/disk claim. See the
[workload and cache boundaries](../performance.md#reusing-unchanged-species-playback-means).
Independent review found no actionable defects in this cache. Regression checks
and a separate 450-frame deterministic comparison against the pre-cache
implementation preserve exact cumulative views through sparse samples,
population/order changes, tick gaps, extinction and independent copies. The cache
adds bounded member references and changes no replay, checkpoint or training
artifacts.
