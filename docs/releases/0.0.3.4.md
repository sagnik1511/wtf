## Overview

Forty maintained algorithm/scenario presets now start new runs with V7 compact
observations, three-step personal visual history and anonymous blended scent.
Preset names, learners and physical calibration remain stable.

## Changes

- Add explicit per-template ordered action contracts; split shared configuration
  templates only where species have different action lists.
- Enable blended smell radius 2 and scent lifetime 32 for newly enabled fields;
  retain existing scent lifetimes and optional social/auxiliary settings.
- Retain the minimal baseline, archived-brain initialization example and named
  V5/V6 comparison controls. Local experimental JSONs are not rewritten.
- Update calibration and migration guidance, including new input widths and the
  distinction between adopted sensory defaults and ecological evidence.
- Keep CUDA benchmark template conversions and older-version comparisons valid
  when their source preset now has an explicit V7 action contract.
- Preserve visual-memory initialization when GRPO trials reuse cached first-frame
  observations, so reused trials match independently restored fresh trials.

## Compatibility and migration

This is an intentional preset observation/model-signature change. Start fresh,
load matching complete V7 signatures, or use the original captured environment
for old warm starts. Exact checkpoint resume and saved playback retain their
captured configuration. Earlier observation versions and private brains remain
supported. No learner objective, map, population, physiology, reward, mating rule,
vision setting or capture cadence is changed by the preset promotion. Optional
late heads remain on their existing reference configuration; no unsupported
learner silently acquires a different objective.

## Fixes and optimizations

Independent `wtf-reviewer` validation confirmed that all 40 promotions preserve
non-sensory controller/species settings and top-level physical configuration;
the five retained presets match their original content. Shared templates split
only to satisfy distinct ordered action contracts, without pooling brains.

The GRPO fix preserves the visual-memory side effect of the cached initial
observation. Reused trials now match independently restored fresh trials for
V7 and legacy V4 tracking, including stale personal sightings, while the real
world and other private controllers remain isolated. CUDA benchmark conversion
retains the selected sensory fields and repairs each destination action order;
older-version comparisons discard the V7-only action-contract field.

Independent targeted review passed 24 tests and Pylint 4.1.4 on the 15 reviewed
Python sources (exit 0, 10/10). No additional actionable finding was identified
in this review. Full-suite and build preflight results are recorded below.
This is a sensory-default promotion and correctness fix; no new runtime speedup
or universal ecological improvement is claimed. Additional-OS and GPU execution
were not performed for this rollout.

## Rollout and rollback notes

Use existing short-name commands for fresh runs. To keep an old brain contract,
run its captured environment rather than editing model metadata or coercing
weights. No existing result/checkpoint/replay is converted or removed. No package
publication, commit, tag or package-version change is implied.
