## Overview

Adds offline and viewer analysis that distinguishes population survival from evidence of useful learning.

## Changes

- Reconstructs feeding, hunting, movement, energy budgets, births/deaths and rewards from consecutive recorded frames.
- Reports sampled optimizer changes, GRPO signal, policy entropy, coverage and early/late windows.
- Exposes read-only analysis in the server and a Behavior and learning viewer panel.

## Compatibility and migration

Behavior rates require adjacent recorded frames. Diagnostics are sampled and inherited counters establish baselines. The whole-run analysis panel can include frames after the current playback position.

## Validation

Adds analyzer tests for exact denominators, terminal actions, missing frames, energy grants and inherited counters; adds viewer summary tests.

## Rollout and rollback notes

Earlier viewers can still play recordings but do not display this analysis. Keep coverage and censoring qualifications with exported statistics.
