## Implementation

The Agent inspector shows the selected animal's own sampled hidden activations,
and **Watch animal brain** opens a larger window following those samples as
replay plays, pauses, steps or seeks backward. Selecting an animal by ID is also
supported. Body/sample steps remain visible; there is no interpolation or attempt
to infer hidden activity from output scores. The view requires no champion archive
or explanation API request. Recording-selection controls are guarded while a
recording operation is in progress.

Existing diagnostic captures sample every living animal using one forward pass.
Compact FP32 hidden-layer arrays are added, with actual prior memory/current GRU
activation for recurrent PPO. No live recurrent memory is advanced or reset.
MAPPO shows its actor's hidden layers; the separate central critic is not an
action route. Existing observations and predictions are not duplicated or rounded.

The separate **Explain saved brain** window analyzes that run's matching archived
species/sex champion on recorded inputs. It provides selectable criteria/action
targets, weighted activation routes, local input sensitivity, prediction
comparisons, activation maps and single-input what-if controls. Follow mode
updates these diagrams on new recorded observation samples while the same replay
plays, with play/pause/step/back controls. What-if pins the displayed sample and
pauses; following resumes at the current playhead and clears the override.
One in-flight/newest-pending queue bounds work and stale responses. Following
adds zero recording bytes, fields or sidecar files. Missing endpoint errors
explicitly request a playback-server restart; Retry is available after errors.
Source model and
observation/body steps distinguish this re-evaluation from actual animal activity.
GRU archive analysis resets unrecorded prior memory; QR-DQN uses mean quantile
returns. Local sensitivity does not claim causal understanding or reconstructed
thoughts, and recorded masks remain fixed for what-if inputs.

The default explanation emphasizes input meanings/influence and action scores.
A shared viewer threshold k defaults to two hidden processing stages. Brains
with rank ≤ k show every unit and complete dense inter-stage topology (bundled
for wide diagrams); deeper brains show a stage-size summary. GRU gates are
collapsed memory blocks; MAPPO rank uses its actor only. Individual neuron maps
and selected weighted routes are lazy Advanced disclosures. Threshold changes
need no new request, saved fields, capture work or model changes. Legacy missing
hidden values are gray declared units, never inferred historical activations.

## Compatibility and optimization

`recording.record_activations` is an optional boolean defaulting to `true`.
Set it to `false` to omit the new visualization arrays. Existing diagnostic
sampling settings control frequency; zero diagnostics disables activation
capture too. Only the new visualization arrays use FP32 storage; simulation,
learning, model state, RNGs and existing prediction precision are unchanged.

Replay diagnostics gain an optional version-1 `activations` field using existing
binary arrays and compression. No new replay codec tags, checkpoint changes,
model signature changes or dependencies are required. Old recordings retain
their predictions and explicitly report absent activation data. New recordings
can show actual activity without saving any champion archives.

Optimization avoids duplicate diagnostic inference, repeated inputs/output arrays,
full weight snapshots and unused critic tapes. Only the selected animal is
rendered, and its DOM is reused between samples. Archived analysis separately
uses bounded packed-model/context caches, shared-blob deduplication, one requested
chunk and one forward/reverse pass. See [activation costs](../performance.md#sampled-animal-activations)
and [archive-analysis limits](../performance.md#on-demand-brain-explanations).

## Adoption and rollback

Restart training/start a new recording to capture activations, and refresh the
updated viewer. Existing recordings cannot recover missing hidden activity.
Restart an existing playback server to load the archived-analysis endpoint.
No data conversion, dependency install or native rebuild is required. Disabling
activation capture restores the previous smaller diagnostic payload. Existing
models/checkpoints remain usable and existing replay data is retained.
