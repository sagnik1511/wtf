## Implementation

Founder initialization generates a fresh controller once per populated
species/sex and loads any selected model once for that group. Other founders
clone its pristine state with their original individual RNG seeds. Networks,
optimizers, buffers, configuration and recurrent state remain independent.
Temporary templates are discarded before learning and do not change champion
selection, legacy retention, offspring inheritance or run-to-run chaining.

CLI recording, CSV, progress and terminal output reuse metrics from the same
completed state when available. Final summaries detach those values instead of
rescanning animals/resources. Optional explicit reports preserve fresh default
behavior for standalone calls; there is no persistent same-tick cache. Snapshot
metric maps remain independently owned, and skipped replay samples stay lazy.

## Compatibility

Simulation rules, precision, model signatures, checkpoint/replay schemas and
viewer behavior are unchanged. Existing artifacts need no migration. No native
rebuild, dependency installation or configuration changes are required.

## Validation

- Seven added regression tests cover all nine controller types, constructor/model
  load counts, original seeded states, independent mutable state, terminal/CLI
  metric scan counts, snapshot/summary ownership and fresh standalone reporting.
- All 486 maintained non-HTTP Python tests and 66 JavaScript tests pass. Seven
  localhost HTTP tests were excluded under restricted network permissions;
  server implementation is unchanged.
- Sixteen pre-change fixtures (137 steps per backend) preserve exact observations,
  complete checkpoints and replay bytes, including terrain, consent versions,
  GRPO/masked opponents, forced births and mutation. Automatic/native and
  Python-only paths both pass.
- Eighteen additional two-run resumed workflows per backend cover all nine
  learners, chaining enabled and randomized worlds with chaining disabled.
  Terminal output and all emitted CSV, summary, binary checkpoint and replay
  artifact bytes match the pre-change implementation on both backends.
- Black (99 Python files), clang-format (4 native files), Prettier (65 web/config
  files) and shfmt (1 shell file) formatting and check modes pass. Documentation
  links/assets and whitespace checks pass.
- A five-pair native benchmark of the 54-founder masked-PPO preset measures
  initialization at 179.7 → 71.1 ms median (60.5% less time) and initialization plus
  32 training/recording steps at 860.9 → 748.4 ms (13.1% less time). Peak traced
  Python allocation is effectively unchanged: 22.09 → 22.07 MiB for the latter
  workload. This does not establish improved sustained per-step throughput or
  total process RAM. State/replay hashes and output sizes match; see the
  [benchmark scope and limitations](../performance.md#measured-initialization-and-reporting-cost).

## Adoption and rollback

Restart training to use the updated Python implementation. Reverting restores
repeated initialization/scans without changing the interpretation of saved data.
