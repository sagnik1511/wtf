## Overview

Recent observation, inspector and champion features needed diagrams alongside
operating instructions. The guides now explain their data flow visually, and
saved-brain instructions consistently describe best-so-far retention and shared
weight storage.

## Changes

- Four new SVG flows cover top-k inputs, current versus sampled inspector state,
  deduplicated model storage and completed-run early stopping. The champion
  chaining flow now shows strict improvement and incumbent retention.
- A controlled inspector illustration shows sight, target slots and example
  action probabilities. Its provenance distinguishes actual constructed inputs
  from invented probabilities; it is not a captured experiment.
- The visual guide and asset catalogs link the new figures where their behavior
  is explained. There are now 27 flow diagrams across 17 guide pages.
- Recent diagrams and the inspector example have repository-native generators;
  `.mmd` intermediates and raster review previews remain ignored caches.
- Chaining prose and the CLI criterion table reflect current options. The deep
  river guide now matches its configured `[64, 16]` prey architecture and parameter
  count; the preset itself is unchanged by this documentation update.

## Compatibility and migration

Documentation and asset generation only. Simulation, viewer, configuration,
models and recorded results are unchanged. No migration, package installation,
training, server restart or screen recording is needed. Reading SVGs requires
no special renderer; regeneration uses Python and the existing Graphviz workflow.

## Validation

- All 27 flow SVGs regenerated identically from local sources; all five recent
  flows and the controlled illustration passed the portable generator check.
- Raster previews of the five recent flows and inspector illustration were
  reviewed for readable labels, layout and clipping.
- All 799 local links/anchors across 91 Markdown files and all 42 documentation
  SVGs passed validation; release navigation and whitespace were checked. No simulation/training suites were run for this docs-only change.
