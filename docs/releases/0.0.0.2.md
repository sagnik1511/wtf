## Overview

Reduces repeated simulation work and large temporary save allocations while preserving the sampled learning and world operations.

## Changes

- Shares observation-phase position/resource data and uses squared-distance filtering while preserving target tie order.
- Uses compact immutable replay experiences, direct entity snapshots and smaller neural forward-pass operations.
- Streams checkpoints one brain at a time and replay frames into atomic chunks; avoids a duplicate final numbered checkpoint.
- Reuses playback snapshots and canvas dimensions rather than rebuilding identical display state.

## Compatibility and migration

Checkpoint values remain compatible at this revision. Programmatic full checkpoint snapshots and checkpoint loading still materialize the complete state in RAM.

## Validation

Introduces reference-based efficiency tests. Historical local measurements and their workload belong in the performance guide; they are not a speed guarantee for other experiments.

## Rollout and rollback notes

Preserve completed results before changing writers. Earlier code can use the unchanged checkpoint values, but does not have these streaming allocation improvements.
