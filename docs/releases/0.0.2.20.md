## Behavior and compatibility

Python quality jobs install setuptools explicitly alongside the pinned tools.
Maintained native-build scripts import it, but Python 3.12+ venv creation and
isolated wheel-backend installation do not supply it to the Pylint environment.
The dependency is development-only; installed simulation/viewer dependencies and
package versions remain unchanged.

The package keeps its lazy `Experiment` export through module `__getattr__`.
Narrow, explained Pylint exceptions cover the dynamic `__all__` entry and the
installation smoke check's public import. The root does not eagerly import
training to satisfy static analysis. A regression verifies star-imported exports
resolve correctly after a lightweight root import.

## Fixes and optimizations

Fixed clean-environment Python quality checks by explicitly installing pinned
setuptools for maintained build-tool imports. Added narrow, explained Pylint
exceptions for the dynamic `Experiment` export and its installation check,
preserving lazy root imports and runtime dependencies. Focused regressions
verify public import identity and complete star-import exports after a
lightweight package import; changed-source Pylint passes in both development
and clean Python 3.12 environments without native binaries. No performance
optimization is claimed.

## Validation

Checks use a fresh Python 3.12 venv with only the declared CI/runtime dependencies
and a tracked-source snapshot without ignored compiled kernels. The baseline
reproduced missing setuptools imports; after installing the corrected dependency
set, Black, full Pylint (174 maintained Python files, zero diagnostics), wheel
creation through the source archive, and strict Twine checks all pass there.

The full Python suite passes 733 tests (22 optional skips), and the focused
packaging/quality suites pass 14 tests. All project formatter write/check modes
pass: 174 Python sources, four native files, 116 web/JSON files and two shell
scripts; 298 source/config files pass syntax/parsing checks. The independent
reviewer verified lazy public/star imports in both environments and found no
remaining actionable issues. Documentation/source-reference tests pass 27 tests; JavaScript checks pass 146 tests.
These local macOS checks are not an executed Ubuntu matrix pass.
