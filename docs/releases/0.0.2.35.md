## Overview

Opt-in V6 expresses already sensed V5 cues as overlapping semantic categories,
preserving per-entity top-k slots and ordinary unmasked PPO. Earlier versions
retain their established meanings and saved-state contracts.

## Changes

- Configurable validated soft knots, circular bearings and rare-outcome bands.
- Exact flags for opportunities, consent, presence and physical readiness.
- Expanded optional history/scent/social blocks, bounded immutable layout cache
  and a 4096-input guard.
- Private auxiliary target decoding with all encoded target channels excluded.
- Semantic inspector disclosures, raw/XAI labels and representative world-frame
  diagrams; exact replay world positions and codecs remain unchanged.
- Explicit seaside V6 preset and selectable matched comparison versions.

## Compatibility and migration

Version and resolved knots enter signatures. V6 needs matching fresh weights;
V1–V5 models/checkpoints remain supported. Values outside represented bands
saturate; category-derived inspector reconstruction is labeled accordingly.
V6 expands input vectors and can increase runtime, RAM and recording/model size.
No automatic preset promotion, package version change, commit or upload occurs.

## Fixes and optimizations

Independent `wtf-reviewer` review verified versioned semantic widths, auxiliary
target exclusion, recorded-heading decoding and preserved physical state. Fixed
caller-owned knot aliasing in private auxiliary targets and browser layout
caches; cached plans now own immutable metadata. Comparison normalization accepts
custom V6 knots while keeping older arms valid and recording treatment knots
separately. No runtime speedup is claimed.

## Validation

Local validation includes full Python/JavaScript suites, all source formatters,
Pylint (10/10), portable wheel/sdist builds and strict Twine metadata checks.
Independent review passed 28 focused Python tests, 18 JavaScript tests, 30
mixed-action phases across five presets with equal physics/RNG/rewards/events/
memory/social state, 72 legacy label contracts and 976 custom-knot in-band
round trips (maximum error `5.69e-16`). Auxiliary target decoding and exclusion
were checked for PPO/masked PPO across all consequence scopes. Controlled
semantic diagrams were rendered in light/dark modes; documentation is built
and checked for local links and homepage reachability. No additional OS or GPU
validation is claimed. Matched study outcomes stay in ignored local summaries,
not in release notes or general operational guides.
