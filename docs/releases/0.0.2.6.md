The contest message previously occupied a separate layout row below the board.
Showing it could change the grid's available height. It now sits inside an
absolutely positioned event-label stack with the kill/death label. Both labels
retain their own colors and stack without overlapping each other; birth labels
remain at the lower board edge. Labels wrap within the board on narrow screens
and do not intercept pointer input intended for animal selection.

The event text, markers, theme handling and playback timing remain unchanged.
No simulation, checkpoint or recording format changes are needed. Refresh the
viewer to load the updated HTML and CSS. The package version stays `0.0.2.0`;
this is an unpublished implementation rollout.
