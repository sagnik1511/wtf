## Overview

Carries selected champions between episodes and lets the viewer navigate every recorded episode in an experiment.

## Changes

- Enables champion chaining by default and adds explicit chain/no-chain flags; default criteria are prey lifespan and predator kills at this revision.
- Starts later runs from the selected model with fresh controller state and preserves original initialization when chaining is disabled.
- Adds run selection, previous/next-run navigation, sequential playback and bounded metadata refresh while recording.

## Compatibility and migration

Modern chaining differs from retaining individual live controllers. Legacy checkpoints keep their original retention behavior. New invocations still start fresh unless a source archive is selected.

## Validation

Adds chaining tests across algorithms, source archives, resets, checkpoint boundaries and CLI runs; extends multi-run playback tests.

## Rollout and rollback notes

Keep legacy/new retention distinctions when resuming older experiments. Restart the playback server and refresh the page to obtain matching run-navigation behavior.
