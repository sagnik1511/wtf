## Overview

Champion export repeatedly encoded and hashed the same configuration for its
criteria. The inspector constructed prediction-history SVGs while their panel
was closed and calculated chart-ready scores twice for each history sample.
The export now reuses configuration references within one call, and chart work
happens when the user opens the history panel.

## Changes

- Export-local configuration cache, keyed by identity with strong references.
  It is bounded to the distinct configurations in that export and discarded
  afterward. Historical configurations remain intact; later exports see edits.
- Lazy prediction-history rendering. A chart uses one score pass per sample and
  is retained on closing/reopening until a new diagnostic replaces it. A closed
  section creates no history chart SVG nodes.
- History sample collection checks finite scores without calculating bar layout
  or mask fields. Scores, timestamps, mixed policy/Q filtering and graph scales
  retain their existing semantics.
- The [performance guide](../performance.md#recent-export-and-inspector-work)
  records cache ownership/bounds and the remaining native top-k candidate.
  Existing storage and inspector diagrams still describe the same data flow.

## Compatibility and migration

No simulation arithmetic, precision, actions, learning schedule, selection rank,
RNG, recording format or model format changes. Archive config bytes and model
values remain unchanged. No new packages or result conversion. Reload the viewer
for updated JavaScript; a running trainer needs a new process to use export-side
changes. Older saved results remain readable.

## Validation

- 66 Python tests passed across export efficiency, model libraries, champion
  promotion, brain chaining, sex-specific champions and early stopping.
- All 65 JavaScript tests passed, including sight parity on 48 Python/JS cases,
  seeking/history bounds, deferred chart construction and signed/zero Q scales.
- New call-count tests check one serialization per configuration identity,
  exact config/model round trips and refresh between exports; closed charts do
  no score processing, and opening/reopening avoids duplicate score passes.
- Documentation links/anchors, SVG generation and whitespace checked. No profiler,
  long training experiment or performance benchmark; no speed/RAM percentage claim.
