## Changes

Optional world-time sunlight rises from sunrise to a midday maximum and fades
through dusk to night. Each species can configure night-time vision, living-cost
and movement-cost multipliers. Effective values interpolate with sunlight; actual
charged costs enter the existing energy feedback. Observation and visible-mate
ranges share the effective sight radius. Reproduction proximity is unchanged.

The viewer derives matching light from recorded tick/configuration: a legible
night overlay, warm dawn/dusk tint, phase/sunlight indicator, frame-synchronized sun/moon orbit and current effective
body values. Board sight follows current light and sampled observation graphics
use their sample time. Seeking and run changes need no independent timer.
A maintained JSON example and source-rendered appearance sheet accompany the
[configuration/compatibility guide](../day-night.md).

## Compatibility and storage

The cycle is opt-in; old worlds retain their behavior. Observation vector sizes,
brain signatures and binary replay formats are unchanged; no explicit clock
feature is added. No per-frame or per-animal data is duplicated into recordings.
Checkpoints reconstruct effects from their saved tick/configuration without RNG
changes. Body dictionaries are cached once per species/tick. Enabled-cycle flat
worlds supply effective costs to native metabolism where supported, with a
Python reference fallback; see [the optimization rollout](0.0.1.28.md). No dependency or native rebuild is required. Refresh the viewer for new
recordings; disable the cycle to return to static body values and lighting.

## Validation

Targeted tests verify the sunlight curve, species modifiers, observation range,
night movement/metabolism costs, disabled-cycle parity and exact checkpoint
continuation across sunrise. JavaScript tests cover sight cache invalidation,
lighting, backwards seeking and cycle metadata across run changes. An 800-step
recording exercises two cycles with normal training and replay output. The
source-rendered sunlight/appearance sheet is checked against current code.

All 519 Python tests and 91 JavaScript tests pass, including the all-presets/
all-algorithms reward contract and localhost HTTP coverage. Black (106 Python),
clang-format (4 native), Prettier (75 web/config) and shfmt (1 shell) format/check
modes pass. Five viewer sheets regenerate exactly; documentation links, SVG
parsing/rendering, the 26 existing diagram checks and whitespace checks pass.

The clock follow-up verifies opt-in visibility, sun/moon positions, pause/seek
behavior and reuse of SVG nodes. The appearance sheet includes the same clock
markup as the viewer. Existing environment presets remain opt-in individually.
