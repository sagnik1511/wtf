## Overview

Separates local benchmark output and reference snapshots from maintained project source.

## Changes

- Adds ignore rules for generated performance measurements, profiles and reference trees.
- Keeps runnable benchmark scripts available for repeatable local checks.

## Compatibility and migration

Ignore rules affect future untracked files. Previously tracked performance files are removed separately in the next rollout.

## Validation

The commit changes Git ignore configuration only; it does not change simulation or training code.

## Rollout and rollback notes

Reverting ignore rules can make local generated files appear in Git status. Preserve the rules when restoring local performance data.
