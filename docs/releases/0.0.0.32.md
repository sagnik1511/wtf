## Behavior

Makes adding named prey/predator species a documented JSON operation. The backend
already iterated arbitrary configured species; new regression coverage verifies
multiple species across physical rules, all learning algorithms, independent
controllers, metrics and species/sex archives. Shipped presets still contain one
prey species and one predator species. [Species guide](../species.md).

The board now builds its legend from actual species names, caches the associated
style map per recorded configuration, and shares base colors with charts. The
first prey/predator retain familiar colors regardless of ordering; additional
species get generated palettes instead of wrapping a fixed list. Optional
`species.<name>.display.color` and `display.male_color` are strict six-digit hex
colors. Male outlines remain. Total prey/predator cards provide species counts
on hover, and predator kill banners identify the actual attacker species.

Validation rejects blank/non-string species names and malformed display objects.
The JSON schema includes display settings. Body/learning/reproduction rules remain
per species: predators can hunt any resource-eating species, while mating requires
an exact same-species pair. Observation indexes still aggregate targets by diet;
there is no new species-ID observation or selective food web.

## Compatibility and adoption

No observation/action/model signatures, dependencies or replay/checkpoint formats
change. Existing records get generated styles when no display metadata exists;
old records without sex retain base colors. Display changes affect new recorded
configurations. Existing saved models remain subject to exact species identity
checks. Refresh the viewer for the dynamic legend. No presets gain additional
populations or altered body/learning defaults.

## Validation

Nine multi-species Python cases exercise four renamed species, all-nine-algorithm
JSON/binary resume, perception/masks/combat, mating isolation, eight champion
pools, warm starts, binary recording, analysis, telemetry and CLI metrics. Four
JavaScript cases cover role-aware defaults, more than five species, deterministic
colors, JSON overrides and attacker species through kill-marker carry. Existing suites also pass. Documentation paths, preset
validation, schema JSON and viewer syntax are checked. The documented cloning
recipe validates without creating another shipped preset. Live viewer HTML and
the new style module both return HTTP 200. No performance or learning
quality improvement is claimed.

## Rollback

Remove display settings from configurations before returning to a validator that
rejects unknown species fields. Existing multi-species physical data can still be
read by the generic replay format. The older viewer retains its fixed legend.
No commits or tags are created by preparing this rollout.
