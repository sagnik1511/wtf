## Overview

Extends allocation and repeated-computation reductions to PPO, A2C, REINFORCE and GRPO without changing learning schedules.

## Changes

- Separates lightweight inference from forward passes that retain activations for backpropagation; PPO/A2C bootstrap only the critic output.
- Reuses local gradient containers across PPO/GRPO minibatches and normalizes fresh advantage vectors in place.
- Reuses the REINFORCE return vector, shares per-trajectory GRPO coefficients and skips reference inference when KL regularization is disabled.
- Omits old lifespan records in GRPO trial clones and uses recorded next-animal IDs without rescanning death history; legacy restoration retains its fallback.

## Compatibility and migration

Rewards, model dimensions, sampling order, optimizer arithmetic, diagnostics and checkpoint formats stay unchanged. Scratch buffers remain local to an update and are not copied into every animal.

## Validation

Recorded validation: 206 Python tests passed. An additional comparison checked exact serialized states against the original implementations over 240 policy transitions, including normalization, KL stopping, unequal trials and resume. No profiler or benchmark was used.

## Rollout and rollback notes

Start a new training process to adopt the implementation. Revert the associated source changes together if a policy regression is found; retain the exact-state and trial-isolation checks.
