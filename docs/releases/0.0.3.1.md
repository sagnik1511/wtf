## Overview

V7 makes the observation representation compact through numeric cues, summaries
and configured-action pruning. An optional private PPO adapter applies learned
consequence adjustments after the physical policy forward pass.

## Changes

- Remove derivable target/mate distances and permanently unavailable action rows.
- Seven-value motion summaries and four-value anonymous off-cell scent bearings.
- Optional bounded learned residual over separately saved local/general/context
  evidence; final probabilities drive sampling and PPO objectives.
- Preserve private optimizer state, inheritance, mutation, warm starts and exact
  recovery; explain base scores, adjustments and final predictions in replay.
- Add a packaged ordinary-PPO seaside V7 preset and themed viewer specimen.

## Compatibility and migration

Opt-in V7 requires compatible fresh model weights and a stable ordered action
contract. Existing V1–V6 configurations, artifacts and behavior remain supported.
This changes representation and decisions; identical trajectories are not claimed.
Scent summaries exclude the current cell and lose alternate directions; motion
summaries omit per-lag paths. Optional late adaptation initially supports PPO and
masked PPO on the reference CPU training path. No package-version change,
commit, tag or publication is implied.

## Fixes and optimizations

Independent `wtf-reviewer` validation corrected V7 malformed-species validation,
made masked before/after consequence comparisons use the same mask, and clarified
archived base-logit diagrams. Compact summaries retain bounded personal sightings
and anonymous off-cell scent; published evidence bypasses the physical trunk
through a private learned residual. Final-policy gradients, KL-gated commits,
inheritance, warm starts and checkpoint recovery were checked. Earlier V1–V6
checkpoint equivalence probes passed. No unresolved behavior decisions or
measured training-speed claim. Layout sizes and tradeoffs are in the V7 guide.

## Validation

The full Python suite passed 847 tests (29 skipped), and all 195 JavaScript
tests passed; targeted checks passed after review fixes. Independent review passed 29 focused Python and 15 JavaScript tests,
scoped Pylint 10/10, twelve source/policy combinations with archived final-output
parity, and FP64 local-gradient probes with maximum error about `1.05e-12`.
V1–V6 three-step complete checkpoint hashes matched a preserved baseline.
All-source formatting, maintained-source Pylint, portable wheel/sdist and strict
Twine checks passed. Viewer generation and both palette previews were checked;
site validation covers links, assets and homepage reachability. No NVIDIA,
additional-OS or long-run ecological improvement is claimed.

## Rollout and rollback notes

Use `seaside_150_v7` or explicitly opt into version 7 with matching templates.
Omit `late_consequence` for a compact early-input policy. Use older presets and
matching saved brains to retain their previous representation. Never relabel
old metadata to force a warm start.
