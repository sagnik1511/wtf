## Result

Reviews all documentation and adds 23 SVG flow diagrams across 16 guides where
ownership, order or branching is harder to explain in prose. Coverage includes
runtime boundaries, the world-step and private learning loops, GRPO isolation,
recurrent/quantile/masked/centralized-critic paths, configuration, species,
initialization and champion chaining, mutation, rewards, playback, binary state,
cache invalidation, evidence/calibration and contributor/release workflows.

[The visual guide](../visual-guide.md) maps questions to individual diagrams.
Existing physics SVGs, interactive examples and full-viewer GIFs remain the
spatial/media reference. README, contributor context and asset catalogs link
these resources. Historical rollout records keep their existing evidence;
new process illustrations live in the hub instead of every historical child.

The guides embed portable SVGs rather than requiring a Markdown Mermaid renderer.
SVGs and a manifest live under `docs/assets/diagrams/`. Editable `.mmd`
sources remain local-only and are excluded by `.gitignore`. `work/build_doc_diagrams.py` parses the supported small
flowchart subset and renders it through Graphviz. This adds no Python/runtime
package and no browser dependency. With local sources available, topology and export freshness are checked; without
them, `--check` validates SVG structure/counts and explicitly reports SVG-only
checks. Unsupported authoring syntax is rejected rather than dropped.

A few adjacent descriptions were corrected to match the diagrams: binary default
checkpoint/replay filenames, terrain action masks and input dimensions, and
independent MAPPO child crossover. No simulation, policy, configuration or viewer
behavior changed. No new training experiments or run data were generated.

## Verification

- All 23 sources parse; Graphviz renders all 23 SVGs and exported node/edge counts
  match their manifests. Rebuilding is deterministic with the installed version.
- SVGs rasterized for review; labels, arrow paths and clipping checked, including
  the more branched architecture, MAPPO and reproduction diagrams.
- Local Markdown/image links, source/catalog references, anchors, XML and diff
  whitespace checked across documentation. Assets contain no personal paths.
- All 23 `.mmd` files remain locally present but Git-ignored; no such files were
  already tracked. Source links were removed from published documentation.
  A source-free temporary checkout validates all 23 SVGs without regeneration.
- Documentation-only checks were used; runtime test suites were not rerun.
- Reconciled rollouts 35–39 with verified implementation commit `2d2e036` dated
  2026-11-17. This maintenance did not create another commit or tag.

## Adoption and rollback

Read the guides normally; SVGs display in GitHub or ordinary Markdown image
viewers. Editing/regenerating the exports requires Graphviz but reading does not.
Remove the new diagrams, helper and links to revert the presentation.
Existing result formats and learned models are unaffected. No package version,
commit or tag was created by preparing this rollout.
