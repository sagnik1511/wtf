## Overview

General action evidence previously disappeared when its physical context left
the bounded memory. Optional persistent species/action totals retain that evidence
separately. Optional private PPO/masked-PPO outcome heads train hidden features
from published physical-outcome estimates, without sharing actor trajectories.

## Changes

- Fixed-width species/action counts follow continuous or episode publication,
  independently of bounded context eviction. Legacy imports bootstrap only the
  rows still present; logical consequence state v3 retains both kinds of memory.
- Each opted-in PPO/masked-PPO brain owns a 36-output supervised head and Adam
  state. Its auxiliary inputs zero consequence estimates to prevent target
  copying. Only own rollout observations train it, after the PPO KL gate accepts.
- Actor rewards, old log probabilities, GAE, clipping and private shuffle RNGs
  remain on-policy. Masked actions may still have supervised outcome targets.
- Head weights participate in model signatures, champions, parental crossover
  and rare child mutation. Checkpoints restore private optimizer state and both
  published/staged evidence exactly. Existing record encodings retain their readers.
- `land_bridge_collective` is an explicit ordinary-PPO experiment preset with
  all episode playbacks retained. The earlier presets keep their original modes.
- Reusable matched comparison helper retains compact summaries only and asserts
  frozen held-out evaluation performs no policy or evidence updates.

## Compatibility and migration

Both changes are opt-in; omission preserves earlier table aggregation and
headless policy behavior. New auxiliary models have a distinct signature and
require compatible weights. Legacy context-only knowledge can warm-start durable
totals, but discarded history cannot be reconstructed. Older source/package
readers do not understand new configuration fields or consequence state v3.
The outer checkpoint/replay codecs are unchanged. Auxiliary PPO currently uses
CPU updates, bypassing the CUDA shortcut that does not implement this objective.
See [compatibility](../compatibility.md#persistent-consequence-totals-and-private-auxiliary-heads).

## Fixes and optimizations

Independent review found and corrected a partial model-import failure: finite
values outside FP32 range could replace the auxiliary head before policy
conversion failed. Both parameter trees now convert before live assignment;
regression coverage verifies rejected imports leave the controller intact.

Review verified independent heads and optimizer arrays, own-rollout-only
supervision, target-input zeroing, PPO KL acceptance, evidence retention across
context eviction, episode publication, legacy bootstrap and exact recovery after
auxiliary updates. Trunk gradients reuse existing PPO gradient buffers. Scoped
numerical/transaction complexity exceptions passed Pylint 4.1.4.

No training speedup or ecological improvement is claimed. The auxiliary objective
remains opt-in; limited matched evaluation does not establish reliable
generalization.

## Validation

Regression coverage checks retention across eviction, frozen episode publication,
legacy bootstrap, malformed totals, independent heads and RNGs, finite-difference
and native/reference gradients, KL rejection, warm starts, child-state reset,
and binary recovery after nonzero auxiliary updates with a pending PPO rollout.
The full Python suite passed 806 tests with 29 skips; all 180 JavaScript tests
and 33 documentation/source-contract tests passed. Full formatting, Pylint,
portable wheel/sdist build and strict metadata checks passed. Matched legacy/persistent/auxiliary treatments used three training seeds, three
900-step episodes and two shared frozen held-out worlds per trained set. First
episode physical summaries matched exactly across arms; frozen evaluations
asserted no model or evidence updates. The small comparison did not establish
consistent held-out survival or reproduction benefits. The site audit checked 1,646 HTML pages and 96,796 local
links/assets/anchors, with all 1,018 audited documentation pages reachable and
zero errors. Homepage click routes cover 310 guides, 116 visual files and eight
runtime copies. Individual
experiment records remain ignored; no long-run calibration is established.

## Rollout and rollback notes

Use the source checkout and a new compatible model for auxiliary training. No
package version, tag, commit or upload is created. Keep the earlier source and
saved configuration for exact continuation of historical experiments. Preserve
new checkpoints and exports before switching to a reader that predates v3.
