## Overview

Animals can optionally receive pooled visible same-species outcomes and shared
species consequence estimates while retaining independent policy learning.
Population knowledge survives episode resets independently of selected champions.

## Changes

- Append 24 collective action-group inputs and 48 outcome-estimate inputs through
  explicit optional brain contracts, schema fields and model signatures.
- Respect sight/occlusion at both ends of witnessed actions; use observed harm,
  feeding and births without exact rewards, identities or hidden death inference.
- Retain bounded coordinate-free species outcome tables, short local histories
  and pending horizon windows. Freeze model training during evaluation/random
  modes and isolate GRPO trial copies. Policy weights/optimizers remain private.
- Save one aggregate model in checkpoint world state and a compact completed-run
  export; support separate compatible `--consequences-from` warm starts.
- Add packaged `seaside_social`, sampled-only inspector charts, themed visual
  references and a linked guide distinguishing biology from training abstractions.

## Compatibility and migration

All features default off; existing observation layouts, presets and artifact
readers retain their contracts. Opted-in policies require matching wider input
signatures and cannot load old weights lacking the blocks. Existing saved
recordings have no synthetic social panel. New replay samples use the existing
feature-vector channel, with no new world-frame/event fields. Exact checkpoint
resume restores all state; standalone model imports require matching species
physical contracts and horizon. No publication or package version bump is included.

## Validation

Regressions cover visibility, species separation and pooled sexes, reward
independence, terminal outcomes, feeding/birth cues, bounded memory, repeated
observations, all policy implementations, exact checkpoint continuation, private
trial state, CLI model import/export, legacy-disabled behavior and themed sampled
viewer decoding. The full Python suite passes 711 tests (22 optional skips), all 145 JavaScript
checks pass, and all-source formatter write/check modes and schema-reference
checks pass. A short two-episode CLI check retains both playbacks and exports
one aggregate model; this establishes plumbing, not biological effectiveness.
Documentation and standalone manuscript builds are checked separately. Biological papers motivate the local mechanism; the global
training pool remains an explicitly documented computational approximation.

## Rollout and rollback

Start with the separate optional preset. Retain original brains/checkpoints when
changing input signatures. Disable both input blocks and consequence settings to
return to ordinary independent policies, using their compatible weights. Retain
completed aggregate exports if desired; no existing playbacks are removed.
