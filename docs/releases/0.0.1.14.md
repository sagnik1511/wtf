## Overview

Applied the mandatory formatting workflow across maintained source files,
including existing and newly added code. Results, dependencies, caches and
generated documentation/media were excluded.

## Changes

- Black 24.10.0 over 94 Python files; nine required reformatting.
- clang-format 22.1.5 over four native C/header files.
- Prettier 3.3.3 over 63 JavaScript/CSS/HTML/JSON files, including its new config.
- shfmt v3.11.0 over the shell entry point, preserving its POSIX dialect.
- Added repository formatter settings for four-space native indentation and
  single-quoted JavaScript strings. Documented pinned, isolated local tool setup.

## Compatibility and migration

Source formatting only; no intended changes to learning, world physics,
selection, model/replay formats or viewer behavior. Development tools live in
`.venv` and `.cache/formatters`; runtime requirements are unchanged. The optional
native extension was rebuilt locally from the formatted source.

## Validation

- All four formatter check modes pass over the same 162-file source set.
- Full Python suite: 447 tests passed with the rebuilt native extension.
- Full JavaScript suite: 65 tests passed. Prettier debug checks passed.
- Black AST safety checks and Prettier debug checks passed; Python and JSON
  source comparisons with the indexed versions also passed.
- All 27 flow SVGs, plus the recent inspector illustration, regenerated
  identically in validation; documentation links/anchors and whitespace checked.

## Rollout and rollback notes

Pending; no commit, tag or package-version change. Formatter binaries and caches
remain local/ignored. No result conversion is required. Reverting formatting and
its settings does not require reverting experiment data or trained models.
