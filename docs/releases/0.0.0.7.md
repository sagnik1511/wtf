## Overview

Allows eligible surviving animals to produce children that inherit learned controller state without inheriting lifetime experiences.

## Changes

- Adds per-species health, energy, age, cooldown and population limits for single-parent reproduction.
- Copies learned networks, relevant optimizer state and exploration settings into independent offspring with new random streams and empty experience buffers.
- Adds parent IDs, generations, birth events, offspring lifecycle handling and cyan birth highlights.

## Compatibility and migration

Omitting reproduction settings keeps births disabled for older environments. Newborn health and energy are configured grants; reproduction is not energy-conserving. Earlier engines do not understand descendant lifecycle state.

## Validation

Adds reproduction tests covering eligibility, inheritance, independent RNGs, terminal learning, restoration, multi-generation trials and playback events.

## Rollout and rollback notes

Keep reproduction-aware code for descendant checkpoints. Disable reproduction in a new environment for a comparison rather than rewriting an existing recording.
