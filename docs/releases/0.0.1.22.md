## Adopted configuration

Promotes the supported flat-world survival settings into the common
`environments/maskable_ppo.json`, replacing the need to choose an exploratory
filename. It starts 48 prey and 6 predators; predator radius is 3, prey radius
2, and kill energy 60. Both brains use observation version 4, with top-k 3 for
prey and 10 for predators. Prey retain relative escape moves, health 40 and
movement cost 0.1; both species use five-step mutual resting consent.

The preset keeps its existing brain architecture, reward/learning multipliers,
randomized-world lifecycle and lifespan champion defaults. Controller-independent
physics, optimizer implementation and viewer behavior are unchanged. Other
algorithm/geography presets retain their own settings; the flat-world profile
is not a universal calibration or a guarantee of deeper predator generations.

## Repository structure

Superseded exploratory environment JSONs remain unchanged locally and are
ignored. Public regression tests use small explicit fixtures for legacy mating
and nearest-only observation contracts, rather than depending on local trial
files. Numerical algorithm fixtures keep their own fixed input contract as
user-facing presets evolve.

## Model compatibility

Old version-1/nearest-only weight banks do not match the promoted input/action
signatures. Start fresh or use compatible version-4 saved brains. Exact resume
and playback retain captured configurations; no saved results or models are
converted. Earlier constants remain available in local controls or Git history.

## Validation

Checks cover preset validation, model/observation dimensions, actual training,
exact checkpoint continuation, physical radius gating, consent/replay behavior
and numerical algorithm fixtures. Source formatters and check modes pass.
Package documentation describes current settings and compatibility; ecological
campaign observations are not part of this implementation record.
