## Overview

Brains can receive general same-species action outcomes regardless of current
state or dynamic action masks. Ordinary body/target inputs remain alongside this
knowledge, allowing each independent network to learn relevance without hard-coded
hunting/mating modes. Masks and physical checks still govern execution.

## Changes and compatibility

Set `consequence_scope: "species_action"` on a template with consequence
observations enabled. The legacy default `context` retains exact-context lookup.
New observations use count-weighted published outcomes across retained contexts;
only real attempts update evidence. Publication timing, outcome labels, context
memory limits and reward ownership are unchanged.

The input width stays 48, but scope is explicit in model signatures, archive/XAI
validation and feature labels. Context-mode models/checkpoints remain supported;
weights are not silently exchanged across scopes. Physical consequence exports
remain reusable when their existing physical/horizon contract matches.
No new persistent table, replay field or checkpoint version is introduced.
The maintained `seaside_social` example and current local seaside DQN scent/day-night
config opt in; other presets keep their mode. The updated diagram shows the two
lookup paths and their separation from independent policies and action execution.

## Fixes and optimizations

Independent review found no actionable defects requiring an additional fix.
Regression checks verify that real hunting evidence remains available to a
same-species observer while attack is masked and after its physical context
changes, without generating outcomes for unchosen actions. Count-weighted
summaries preserve exact species boundaries, publication timing and legacy
context-mode behavior; incompatible policy scopes are rejected explicitly.

A derived per-species cache reuses published action summaries. Continuous
learning and episode publication invalidate only modified species; staged
outcomes remain invisible and restored/trial worlds own independent caches.
No persistent table or artifact version was added. Cache reuse and invalidation
are verified; no measured speed or memory improvement is claimed.
