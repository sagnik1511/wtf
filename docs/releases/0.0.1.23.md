## Implementation

Observation production reuses its occupied-cell mapping when preparing mating
population/readiness data. Masked-PPO refresh and masked opponents in GRPO trials
consume that unchanged phase explicitly, avoiding redundant maps, population
counts and personal-eligibility checks. Standalone calls still read fresh state;
no automatic same-position or same-tick cache is introduced.

Boolean birth availability stops at the first valid candidate without building
ordered/deduplicated lists. Actual births use the complete original-order unique
sequence, preserving seeded choices. The birth resolver still checks eligibility
after movement, combat and energy costs. Observation range and mask visibility
remain separate contracts; physical rules, consent and rewards are unchanged.

## Compatibility

No configuration, model-signature, checkpoint, replay or viewer format changes.
Phase data is transient and independently reconstructed after restore and inside
trial worlds. Existing exact checkpoints and saved recordings remain supported.
No native rebuild or saved-artifact conversion is required.

## Validation

- Eight added regressions cover phase preparation counts, early exit, unchanged
  RNG/state, direct edits, terrain/cell order, visibility contracts, post-cost
  eligibility and independent restored contexts.
- The 479 maintained non-HTTP Python tests and all 66 JavaScript tests pass.
  Seven localhost HTTP tests were excluded; server code is unchanged.
- Sixteen short pre-change reference fixtures compare all nine learners, legacy
  and current consent layouts, terrain, mixed GRPO/masked policies, forced births
  and mutation. Observations, complete checkpoints and replay bytes match on
  automatic/native and Python-only backends.
- Repository-wide Black, clang-format, Prettier and shfmt formatting/check modes
  pass. No speed, peak-memory or disk-size benchmark is claimed.

## Adoption and rollback

Restart a training process to use the implementation. No preset or data migration
is needed. Reverting this implementation restores the prior recomputation path
without reinterpreting stored state or recordings.
