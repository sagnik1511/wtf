## Changes

Each board draw calculates sunlight once and passes it to ground illumination,
night shading, the sun/moon dial and selected-animal body calculations. The same
effective body is reused for the sight caption, overlay cache key and visibility
geometry. Paused/unchanged dial phases skip orbit trigonometry and SVG updates;
unchanged sunlight labels skip text writes, while disabled cycles skip hidden
label construction entirely. This uses frame-local values rather than an
unbounded cache or independent timer.

Cycle-enabled flat worlds can again use the existing native metabolism kernel.
A lazy per-species configuration view supplies the exact effective body values;
the kernel still receives the same costs, feedback rules and animal state. The
view is bounded by configured species, expires at the next tick and is built
only if native metabolism needs it. Terrain and unsupported-kernel cases retain
the Python reference path. No native source change or rebuild is required.
Restored/trial worlds rebuild private ephemeral views rather than sharing them.

## Compatibility and validation

No simulation settings, learning cadence, numeric precision, RNG use, replay
fields or viewer controls change. Six source-rendered viewer SVGs remain
byte-identical. No throughput/RAM percentage is claimed without measurement.

An exact 120-step native-versus-reference test covers the cycle, actions,
starvation, events, rewards, observations and checkpoint equality. Cache tests
check one sunlight calculation per world tick and restore isolation. Viewer
checks verify shared sunlight/body inputs without hidden recomputation and
paused clock reuse. See the performance guide for ownership and bounds.

The affected Python suites pass 105 tests (cycle, all-algorithm feedback, native
kernels, geography, caches, reproduction and checkpoints); all 99 JavaScript
tests pass. Repository-wide formatter/check modes pass for 106 Python, 4 native,
77 web/config and 1 shell files. Documentation links and whitespace checks pass.
