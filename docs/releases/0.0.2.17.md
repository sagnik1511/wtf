## Overview

Six editable map/preset pairs add open plains, coastal and interior geography
without changing terrain physics or existing environments.

## Changes

- Bundle `grasslands`, `seaside`, `rolling_hills`, `wetlands`, `canyon` and `oasis`.
- Base their ecology/learning on current ordinary PPO: 64 prey/6 predators,
  version-4 observations and proximal mating radii 2/3. Wet maps add swim and
  existing water sight bonuses; dry maps omit swim. Explicit map obstacles
  replace scattered generation for reproducible landscape geometry.
- Generate themed static map diagrams from the JSON, link them in the geography
  gallery and add a preview freshness check. Render vector arrows from actual
  current direction and use theme-appropriate water/elevation colors.
- Include all new presets/maps in packaged assets.
- Set rolling-hill uphill energy costs to 3.0 / 4.0 for prey/predator. Existing
  energy accounting gives proportional negative reward, without direct health
  damage, speed changes or broader reward-coefficient changes. Document this
  effort setting and its unevaluated population-balance tradeoff.

## Compatibility and migration

No schema, world physics, artifact format or existing preset changes. The new
wet action signatures require compatible weights; fresh starts need no migration.
Use each preset by short name or editable JSON path. Existing recordings keep
embedded geometry. No package version bump or publication is included.
These are stylized layouts, without new tides, heat, concealment or vegetation
mechanisms. Longer-term population/reproduction calibration remains unevaluated.

## Validation

Checks cover connected traversable geometry with one-unit climbs, sufficient dry
spawn capacity, dry founder/food placement, species policy/action/radius contracts,
unique layouts, themed preview structure and short CLI runs with exact map and
replay decoding. The full Python suite passes 693 tests (22 optional skips), including geography,
packaging and policy checks; all 140 JavaScript checks pass. All-source formatter
write/check modes and preview freshness checks pass. Documentation link/access
checks validate the published navigation and assets.

## Rollout and rollback

Try one run before long training. Removing the six newly added preset/map pairs
and their packaging/docs entries reverts availability without altering saved runs.
