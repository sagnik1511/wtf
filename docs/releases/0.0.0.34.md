## Behavior

Proximity previously triggered eligible paired births automatically. Both parents
now must choose `reproduce` in the same step, within range and satisfying all
existing physical gates. Failed attempts charge no birth energy or cooldown.
Successful births preserve crossover, independent child state and rare mutation.
Maskable PPO checks physical availability without consuming RNG or guessing consent.

Dry highlands now omits the unnecessary swim action; wet presets retain it.
Species action lists remain explicit per-environment JSON settings.

All presets append the reproduce action and configure energy-demand feedback
(-0.01 per energy), failed-action feedback (-0.05) and successful-parent reward
(+1). Terrain costs, failed movement/swimming, missed attacks/feeding and blocked
mating now have direct configurable feedback, alongside existing harm/death
penalties. Optional omitted coefficients are zero. MAPPO retains species-mean
aggregation. See [reward accounting](../rewards.md) and
[configuration](../configuration.md#reproduction).

Dashboard/analysis add failed choices, reproductive attempts and successful-parent
ratios. Terminal failed choices retain an event for reward reconstruction;
living actors reuse existing action/reward fields. No duplicate world snapshots
or runtime dependency is added. Sparse-diagnostic frames show current action and
reward in the inspector.

## Compatibility and adoption

The extra action changes model output signatures. Start fresh with updated
presets or load an exactly compatible champion. Old checkpoints remain readable,
but controllers without a reproduce action cannot breed. Observation dimensions
remain 20/32. Restart training/server processes to adopt code and telemetry;
older telemetry shows missing values for new metrics. Birth choices remain
partially observed and no improved learning or stable population is claimed.
