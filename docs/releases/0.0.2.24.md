## Overview

Collective outcome charts now show time averages through the current replay step.
Species summaries live in **Metrics dashboard → Species collective outcomes**;
individual summaries live in **Agent inspector → Collective learning**.

## Changes and compatibility

The viewer averages recorded witness and consequence inputs, holding the latest
saved sample forward between samples. Species summaries average available
living-animal inputs per step before accumulating over time. Unknown evidence is
excluded from outcome rates; missing initial samples are not treated as zeros.
See the guide for step weighting, coverage and interpretation.

Current-chunk rewinds use a compact chunk-start aggregate. Distant seeks stream
older chunks and retain aggregates rather than frame histories. Birth/death,
selection changes and episode resets preserve independent animal lifetimes.
Charts update existing SVG nodes and use theme-aware colors. The controlled
[visual reference](../viewer-visual-reference.md#collective-learning) shows both
placements using actual chart components.

This is viewer-only: learning, observations, rewards, prediction charts,
consequence publication and stored artifacts are unchanged. Existing recordings
with saved collective inputs work without conversion. No new replay fields or
stored histories are required. The new viewer modules are included in packaged
runtime assets. Package version and publication are unchanged.

## Fixes and optimizations

Independent review corrected a backward-seek visibility defect: species panels
now hide when the playhead precedes their first saved evidence, preventing later
averages from remaining visible. Regression coverage verifies disappearance,
restoration using the same chart nodes and empty-prefix visibility.

Running totals retain living-animal and species accumulators plus one detached
chunk-start copy; older prefixes are streamed rather than retained as a frame
history. Dashboard and inspector updates reuse SVG nodes. Tests verify elapsed-step
weighting, unknown-evidence denominators, per-step species means, raw-input
preservation, backward/direct seeks and reset cancellation. No throughput or
peak-memory improvement is claimed for this additional viewer feature.

## Rollout and rollback

Refresh the viewer to load the new JavaScript. No training or recording
conversion is needed. Reverting the viewer restores the previous instantaneous
charts without changing saved data.
