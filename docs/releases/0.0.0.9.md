## Overview

Limits observation work to nearby spatial candidates and reuses observer windows as animals move.

## Changes

- Introduces a spatial index and incremental entering/leaving bucket-window updates.
- Reuses nearest-target results while relevant bucket versions remain unchanged, invalidating on moves, births, deaths and resource changes.
- Preserves visibility, insertion-order ties and restored-world behavior; trims neural gradient work that is not needed at the input layer.

## Compatibility and migration

Spatial caches are derived state and are rebuilt after restoration. Authoritative world state remains the source of truth, including manual edits used in tests.

## Validation

Extends efficiency tests and adds incremental-perception tests for movement, occlusion, ties, mutations and restoration.
