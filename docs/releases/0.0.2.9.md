## Overview

Large campaigns can retain metrics, checkpoints and champion weights without
writing training replay files, then record fresh inference episodes. Full capture
remains the default. Compact capture retains configured world frames with fewer
inspector samples and no hidden activations.

## Changes

- Add mode-aware `recording.profile` and `--recording-profile`, effective capture
  metadata, configuration validation/schema and persistence on training resume.
- Evaluation/random use full configured capture; explicit no-record/disabled
  capture still wins. Disabled recorder construction creates no replay directory.
- Add optional evaluation-only `--freeze-brains` and Python constructor setting.
  Parents never learn; newborns copy a same-sex parent model without crossover or
  mutation. Physical births remain enabled. Ordinary evaluation is unchanged.
- Checkpoint the frozen policy and default missing legacy metadata to false.
- Keep unadopted replay-storage benchmark files locally, ignore them in Git and
  remove their public documentation routes.

## Compatibility and migration

Replay/champion formats and default training behavior are unchanged. Profiles
change capture, not world RNG, learning or artifact retention. Training-only runs
have no historical playback. Inference recordings describe new simulations.
Older package validators cannot load profile-bearing configurations/checkpoints;
use current source. No package-version bump, publication or artifact conversion.
See [compatibility](../compatibility.md#optional-training-capture-and-frozen-evaluation).

## Rollout and rollback notes

Use `--recording-profile training-only` for opted-in training, then `--mode evaluate
--freeze-brains --brains-from ...` for recorded inference. Keep source champions
and required recovery metadata. Revert to `full` to retain future training replay;
missing historical training frames cannot be recreated from champions. Existing
playbacks and local benchmark files are retained.
