## Change

Require Python 3.12+ in package metadata and source imports. Recreate the local
`.venv` with Python 3.12.9, preserving the old environment as an ignored rollback
backup. Update installation/development guides and the viewer launcher's fresh
venv selection. Docker defaults to Python 3.12 slim; containers were not run.

The previous native implementation supported only CPython 3.9–3.11 because 3.12
changed builtin float summation. Port native reductions for dense inference,
softmax, policy entropy, Adam clipping and GRU forward/backward to compensated
summation matching CPython 3.12–3.13. Keep explicit `+=` loops, parameter storage,
RNG/event order and serialization formats unchanged. Validate exact gradients,
optimizer state, cross-backend checkpoint continuation for all nine learners and
decoded replay frames. Cancellation, signed-zero and non-finite cases guard the
new summation path. Reference Python remains available with `WTF_KERNELS=python`.

Native build tools and runtime dispatch now support CPython 3.12–3.13. Newer
interpreters use Python until their native arithmetic is validated; explicitly
requesting an unsupported native build/backend reports a clear error.

Pin packaging CI to Ubuntu 24.04 x64, avoiding interpreter download failures
caused by a moving `ubuntu-latest` image. Portable wheel/source checks cover
3.12/3.13/3.14. Native 3.12/3.13 jobs run both full Python backend selections and
verify installed native wheels outside the checkout. A pushed workflow execution
must confirm Ubuntu results; local macOS checks are not an Ubuntu pass.

## Compatibility and migration

Use Python 3.12+ to recreate environments and reinstall dependencies; rebuild
compiled extensions rather than copying them between Python versions. See the
[development upgrade steps](../development.md) and [compatibility policy](../compatibility.md).
Older Python installations are rejected. Package version remains the unpublished
`0.1.0`; no checkpoint, champion, observation or replay format changes are made.

Existing supported saved artifacts retain their readers and viewer behavior.
Exact historical continuation across the Python upgrade is not promised: float
`sum()` differs from Python 3.9–3.11. Retain the old source and interpreter when
reproducing those trajectories. Restore a backup venv to its original creation
path when rolling back, since console-script shebangs contain that path.

  workflow/Compose YAML formatting and shell syntax are checked separately.
