## Overview

The existing straight river and terraced/enclosed landscapes offered limited
variation in crossing and navigation. Four optional JSON map/environment pairs
add winding channels, distributaries, mountain passes and isolated lake islands
using the existing simulation and viewer rules.

## Changes

- `meandering_river`: continuous river bends, slow margins, two shallow fords
  and low dry knolls.
- `river_delta`: an upstream channel branching into three downstream channels.
- `alpine_pass`: stepped elevation, rocky crests and two broad low crossings.
- `lake_islands`: shallow shores, a deeper still basin and three dry islands.
- Meandering river uses independent A2C prey and GRPO predators; the other three
  presets use PPO for both species. Existing paired reproduction, birth mutation
  and physical/population settings are retained from the PPO river preset.
- Static SVG diagrams and a dependency-free regeneration helper document the
  actual map layouts; these are explicitly separate from viewer recordings.
- Reconciles the preceding native rollout with verified commit `abd310d`.

## Compatibility and migration

Existing presets, terrain rules, learning, model precision, native kernels and
recording/checkpoint formats are unchanged. New presets use terrain observation
version 2 (32 inputs). Wet presets retain the river action lists; loading brains
also requires the selected algorithm's matching signature. The dry alpine preset
omits swimming and requires a matching dry action signature.
Maps embed into saved configurations as before. No extra packages are needed.

## Validation

- All 38 geography/configuration/world/learning/experiment tests passed, and
  all 50 JavaScript viewer tests passed. The HTTP-server test class could not
  bind a localhost socket in the sandbox and was excluded from the successful
  focused rerun; no server code changed.
- CLI smoke checks validate cross-language replay decoding across chunk boundaries
  and map metadata without repeating geometry in individual frames.
- Mixed A2C/GRPO lifecycle checks confirm both learners update and exact
  checkpoint continuation preserves the next step.
- Layout checks found two dry walking components for the meander, four for
  the delta, one for the alpine map and four for the lake (mainland plus three
  islands). Wet crossings intentionally separate the dry regions. All 1,107
  unblocked alpine cells connect using at most one-unit elevation transitions.
- All 131 local links across the affected guides/release/asset documents
  resolved, all four SVGs parsed, and all four rendered previews were inspected.

No long training or population/reproduction calibration is claimed.

## Rollout and rollback notes

Select a new JSON preset explicitly; see the geography guide for commands.
There is no default environment change or server protocol change. Returning to
an existing preset leaves historical recordings usable because their map is
embedded. No commit, tag or package version change is created by this record.
