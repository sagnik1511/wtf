## Result

Adds three 3.5-second GIFs under `docs/assets/terrains/`, cut from the supplied
2026-11-17 screen recordings of river crossing, highlands and enclosed valleys.
The entire recorded viewer frame is retained, including controls, counters,
board, sidebar and visible chart area. No spatial crop or synthetic rendering.

The [geography gallery](../geography.md#recorded-terrain-previews) embeds all
three. README, playback, physics and asset guides link the gallery. The
[asset catalog](../assets/terrains/README.md) and manifest retain exact source
basenames, SHA-256 hashes, relative cut intervals and experiment identifiers.

`work/export_terrain_gifs.py` recreates the assets with FFmpeg/ffprobe and no new
Python package. Palette generation and differential rendering keep all three
around 1.94 MB. Temporary palettes live in ignored cache and are cleaned up.
Source MOVs, results and models are not added to Git. No runtime behavior changed.

## Verification

Each GIF decodes successfully: 1280 × 718, 42 frames, 3.5 seconds, infinite loop.
Decoded frame hashes vary throughout each clip, confirming active playback.
Source and exported frames were visually inspected for terrain identity, full
frame coverage, readable controls and sidebar. The paused highlands opening was
excluded. Source paths are portable, relative links resolve and whitespace is
clean. No training or broad unit-suite rerun was needed for these media edits.

## Adoption and rollback

The Markdown GIFs render directly on GitHub. Use the export helper with the three
original recordings to regenerate them. Clips preserve recorded playback timing,
with the source 60 fps sampled to 12 fps. They are UI demonstrations, not learning
benchmarks. Removing the gallery/assets/helper reverts documentation only.
No commits, tags or package versions were created.
