## Overview

Species can opt into adjacent opposite-sex founder placement through
`spawn.mode: "adjacent_pairs"`. Default/random spawning retains its original
seeded behavior. This is a reusable configuration feature, not an experiment
preset or an experiment-results release.

## Changes

- Pair existing same-species female/male founders before independent brain
  initialization, preserving sex-specific weights and private controller state.
- Prefer female anchors, with a disjoint-cell matching fallback for crowded
  layouts; fail clearly when the region cannot hold enough adjacent pairs.
- Respect dry cells, obstacles, bidirectionally walkable slopes and configured
  inside/outside founder zones. Use isolated placement RNG.
- Document the option in the [species guide](../species.md#adjacent-founder-pairs)
  and generated field reference. Existing packaged presets stay unchanged.

## Compatibility and migration

Omitting `spawn` or selecting `random` preserves prior placement. Adjacent mode
requires an even founder population. New-world placement does not reapply during
checkpoint restoration or alter newborn placement. Sex, heading, age, health,
energy, consent, mating radius, model signatures and replay formats are unchanged.
Existing viewer frames display saved positions without new rendering fields.
No package-version change or publication is included.

## Fixes and optimizations

Independent review found no actionable defects in the adjacent-placement change.
No additional fixes or performance improvements were needed or measured; the
matching fallback runs only during founder initialization and adds no per-step
cache. Exhaustive small-grid checks against an independent matching oracle cover
disjoint capacity and slope restrictions. Comparisons with the base implementation
verify omitted/explicit-random layouts, subsequent steps and RNG state; focused
tests also verify paired placement, body-state preservation, brain initialization
and checkpoint/GRPO restoration without respawning. Changed-file Pylint passes;
the narrow complexity suppressions preserve the ordered placement and matching
phases. See the [species guide](../species.md#adjacent-founder-pairs) for the
placement and compatibility contracts.
