## Overview

Existing guides covered behavior but some structures were harder to understand
from field lists or data-flow diagrams alone. Six focused illustrations now
explain checkpoint ownership/access, observation packing, overlapping families
and spatial-window references. Other subjects retain clear tables, prose and
existing visual cross-links.

## Changes

- A checkpoint guide and three block diagrams show file metadata/brain/shared
  records, optimizer/RNG/buffer state, restoration and runtime consumers. It
  distinguishes algorithm-specific state and whole-checkpoint loading from
  bounded viewer replay.
- A packed-vector diagram shows self/target/terrain/mating sections and repeated
  target slots. The mating guide now explicitly scopes its index table to k=1.
- A pedigree and two family ledgers explain founder set union and strongest-family
  selection without double credit within a family.
- A bucket/window illustration explains shared references, overlap reuse,
  revision-based target invalidation and per-world cache lifetime.
- AGENTS.md and the development/visual guides record selective visualization:
  use figures for helpful relationships/structure; prefer clear tables or prose
  for comparisons, numeric reports and straightforward instructions.
- Feedback review links the existing reward diagram instead of duplicating it.
  The visual guide records which reviewed areas keep their existing formats.
- Reconciled committed rollouts 1.5–1.14 with `91697aa` and 1.15 with `f3d5a1a`.
  The checkpoint additions made after that commit belong to this pending record.

## Compatibility and migration

Documentation, agent guidance and SVG sources only. No runtime, numerical,
configuration, replay or checkpoint-format changes. Generated review previews
remain ignored. No new packages, training run, conversion or server restart.

## Validation

- Checkpoint record order, shared-value detachment, nonempty replay/rollout,
  nonzero Adam moments, RNG restore and exact future steps checked with short
  fixtures. Existing binary-continuation test passed for all nine algorithms
  with XZ/gzip.
- Controlled lineage check confirmed repeated ancestry, unique membership,
  generation qualification and strongest-family rank.
- Checked actual vector dimensions/offsets, overlapping window object identity,
  query reuse and stationary-observer invalidation.
- Three focused existing observation tests passed for ties/padding, lifecycle/
  food/wall changes and small/wide scan paths.
- Raster previews reviewed; local links/anchors, SVG structure, release statuses/
  navigation and whitespace checked. No full training suite or benchmark.
