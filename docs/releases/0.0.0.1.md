## Overview

Makes repeated experiments vary by default and improves inspection of recorded outcomes without coupling rendering to training.

## Changes

- Adds randomized world-seed streams alongside fixed and incrementing policies, plus explicit CLI seed controls and saved seed provenance.
- Adds natural-death markers and lightweight population/food history that survives chunk transitions and seeks.
- Updates hunting feedback and physical defaults, and fits the playback board and controls within a desktop viewport.

## Compatibility and migration

Use an explicit seed and seed policy for reproducible comparisons. A playback-speed change affects display only; randomized invocation defaults intentionally change future layouts.

## Validation

Adds randomization and hit-reward tests and extends recording and playback tests, including history and death markers.

## Rollout and rollback notes

Restart the viewer server and refresh the page after adopting the UI/API changes. Older source defaults may generate different worlds and combat outcomes.
