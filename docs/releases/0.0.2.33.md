## Overview

Optional 150° and 180° forward vision limits fresh visual information to the animal's
front sector or half-plane. Existing configurations retain 360° sight by default.

## Changes

- Per-species body setting filters target slots, visible mates and consent,
  fresh visual-history updates and local witnessed outcomes.
- Stationary turns invalidate directional perception/overlay caches. Existing
  radius, water extension, night range and wall occlusion still apply.
- Native top-k kernels receive front-filtered candidates with the existing ABI.
- Viewer current-sight overlays and sample-heading inspector sectors match the
  saved species setting. `land_bridge_collective` uses 180° for both species;
  `land_bridge_collective_150` uses 150° with the remaining settings unchanged.

- `seaside_150` combines 150° vision for both PPO species with visible social
  outcomes, both consequence scopes, durable totals and private auxiliary heads
  (coefficient `0.1`), publishing evidence between episodes. Map, body/reproduction
  and PPO update settings remain those of seaside. Its larger observation/model
  contract requires fresh compatible weights; the earlier plain preset's brains
  cannot be reused unchanged.

## Compatibility and migration

No policy input width, action vocabulary or replay frame format changes. Scent,
learned memory, adjacent physical affordances, movement, mating radius and
mutual consent retain their semantics. New configuration requires a reader that
supports the field; old recordings default to circular sight. Policy weights
can transfer under existing signatures; changed perception requires evaluation.
Shared consequence exports require a matching body contract. No ecological
improvement is claimed, and earlier 360° comparison results do not validate narrower fields.

## Fixes and optimizations

Independent `wtf-reviewer` review verified heading- and angle-sensitive
perception caches, native/reference candidate filtering and consistent visual
boundaries for targets, mates, history and witnessed outcomes. Existing 360°
defaults, physical eligibility and omnidirectional scent remain intact. The
existing native kernel ABI is retained; no runtime speedup is claimed. A narrowly
scoped Pylint exception documents optional CPython-extension introspection in
the native-dispatch test.

## Validation

Regression checks cover cardinal half-planes and side boundaries, own-cell
visibility, native/reference top-k equivalence, stationary turns, front-only
water extension, hidden visual witnesses/mates, fading history, omnidirectional
scent, explicit/omitted 360° equivalence and checkpoint continuation. Viewer
checks cover sample sectors, directional cache invalidation and Python/JS
visibility parity across terrain, headings and day/night. Local validation passed
816 Python tests (29 skipped), 184 JavaScript tests, 29 documentation/source
checks, all maintained-source formatters, Pylint (10/10), portable wheel/sdist
builds and strict Twine metadata validation. Independent geometry checks covered
44,652 points/headings and mixed-species native/reference observation checks.
The new controlled viewer figure was rendered in light and dark themes. Website
link and homepage reachability checks cover the generated site. No GPU or
additional OS matrix validation is claimed.

## Rollout and rollback notes

Use the source preset or set the field on chosen species. Preserve matching
source/configuration for exact historical continuation. New visual fields apply
to new recordings; metadata in existing recordings is not rewritten. No package
version, tag or upload is created.
