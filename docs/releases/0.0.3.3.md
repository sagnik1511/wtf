## Overview

V7 training and recording remove redundant observation/evidence intermediates
without changing animal learning, saved values or the viewer interface.

## Changes

- Assemble compact social rows directly and reuse immutable published general rates.
- Stage private auxiliary targets once per PPO update, with no redundant V7 evidence padding.
- Batch auxiliary forward/loss/backward in an optional ordered CPU kernel.
- Compute stock inspector late residuals once, preserving custom provider hooks.

## Compatibility and migration

No configuration, observation version, model signature or artifact format change.
All recordings and checkpoints remain compatible. Rebuild optional native kernels
and restart Python to load the new auxiliary entry point. Older builds and custom
hooks retain reference execution; no CUDA implementation change is included.

## Fixes and optimizations

Independent `wtf-reviewer` validation checked compact observation projection,
private auxiliary targets/gradients, KL-gated updates, native input validation
and unchanged saved diagnostics. Review found that compact social queries could
reorder calls to custom consequence providers; the fast path now requires stock
provider identities, and custom providers keep canonical action order before
projection. Regression checks cover stateful general, contextual and aggregate
providers, including exact call sequences.

Targeted independent review passed 46 tests. Post-fix checks passed 68 focused
tests and scoped Pylint 4.1.4 with no findings; all maintained-source formatters
and their check modes passed. The private test fixture keeps its reference
projection and call-history locals together with a narrowly justified Pylint
suppression; mutable default state was removed.
Matched benchmark evidence verifies complete checkpoints, work counts and replay
bytes; published-evidence training measured 1.38× ordinary / 1.38× masked PPO
speedup, with broadly similar peak RSS. None of these optimizations changes
recording cadence or removes playback data. No unresolved review finding remains
in this scope; additional operating systems and CUDA execution were not tested.

## Validation

Matched local measurements show 1.38× ordinary / 1.38× masked PPO speedup with
published evidence; first-episode speedups are 1.12× ordinary / 1.01× masked PPO.
All paired complete checkpoints, work counts and compressed replay chunks matched.
Peak RSS is broadly similar overall. See the linked performance guide for
workload, measured numbers and limitations. Final validation passed all 860 Python
tests (5 skipped), all 195 JavaScript tests, all maintained-source formatter checks,
full Pylint, portable wheel/sdist builds and strict Twine validation. Zensical
built 325 pages; the access catalog proved homepage routes to all 325 pages,
124 visual assets and 8 runtime copies. Native arithmetic was validated on local
CPython 3.12/macOS ARM64; no additional-OS or GPU execution is claimed.

## Rollout and rollback notes

No conversion or deletion of saved experiments is required. Reverting the fast
paths requires no data migration; an older native extension uses Python fallback.
This record does not publish, tag, commit or change the package version.
