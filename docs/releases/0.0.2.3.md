The optional C extension adds ordered multi-target selection to the existing
spatial-index workflow. Query-local native records replace Python distance/
candidate tuples, sorting and individual ray-call dispatch. Sorting, self
exclusion, insertion ties, occlusion and directional water range retain their
reference behavior. Final feature arithmetic and cache ownership stay Python.

No precision, model signature, learning cadence, RNG or stored format changes.
The existing k=1 selector and custom callbacks keep their paths. API-2 extensions
without the new symbol fall back safely; explicitly rebuild to activate it.
The package version remains unchanged; this record does not publish a package.

## Validation and measurement

- CPython 3.12 native build succeeded. Full Python suite: 595 tests, 22 skipped;
  all executed tests passed. Focused native suites: 35 passed. Python-reference
  suites: 36 tests, six skipped, all executed tests passed.
- CPython 3.13.5: native build succeeded and the same 35 focused tests passed.
- JavaScript: 107 passed; six maintained viewer sheets regenerate byte-for-byte.
- Documentation/source tooling: 27 tests passed. Whole-source Black,
  clang-format, Prettier and shfmt formatting/checks passed.
- All nine controllers have matching per-step checkpoints and short binary/XZ
  replay chunks. Matched five-sample, 240-step/phased probes preserve state
  hashes; day/night training plus recording preserves all 515,708 replay bytes.
- Isolated observation probes improve 1.56–2.11×; whole training improves
  1.05–1.08× and recording 1.05× on the local workloads. Peak process memory is
  not consistently lower. See the kernel guide for methods and full tables.
- Strict documentation build and homepage/visual/link audits are checked before
  completion. Benchmark artifacts stay in ignored caches, with a maintained
  runner under `work/performance/top_k.py`. No ecological trial history is added.

## Rollback

Use the reference backend or a previous extension without `nearest_many`.
No checkpoint, brain or replay conversion is needed.
