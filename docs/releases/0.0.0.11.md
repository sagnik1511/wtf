## Overview

Preserves selected per-species learned weights across experiments and moves detailed instructions out of the project README.

## Changes

- Adds independent health, kill, lifespan and energy-gain champions, recording weights when each record is set.
- Exports compatible model generations with provenance and supports initial-model selection without carrying experience buffers.
- Adds dedicated guides for configuration, algorithms, analysis, archives, architecture, recording and development.

## Compatibility and migration

Champion artifacts contain model parameters and provenance, not exact optimizer or world state. Use learning checkpoints for exact continuation. Library files and generated results stay local.

## Validation

Adds model-library tests for compatible loading, independent agents, immutable snapshots, ancestry and missing external-library restoration.

## Rollout and rollback notes

Retain the archive alongside experiments that reference it. Older source has no champion-library interface.
