## Overview

Food and obstacles are recognizable board objects instead of flat colored cells.
Food becomes a rooted leafy patch whose size and leaf count follow saved quantity;
zero quantity shows a bare stem. Obstacles become fixed faceted rocks, with their
whole cell still blocked. Gentle sway and surface shimmer follow saved steps.

## Changes

- Add a packaged canvas-only environment-object renderer, reused by controlled
  documentation specimens. Existing animal/event/terrain drawing order stays intact.
- Derive decorative phase from tick and cell coordinates. Pause freezes motion;
  seeking reproduces it. No browser animation timer, random sampling, image asset,
  history buffer, replay field or backend computation is introduced.
- Honor live OS reduced-motion changes: sway and shimmer become static while
  actual food-quantity changes remain visible. Light/dark palettes and existing
  day–night lighting remain supported.
- Regenerate board, lighting and terrain references from the current drawing code;
  add a themed phase/reduced-motion sheet linked through the visual guide.

- Add tick-linked directional river crests and a four-frame food-gain dot beside
  confirmed eaters. Restore bounded cues during seeking, including tiny legacy
  chunks, without adding replay fields or playback delays. Reduced motion keeps
  cue size/opacity and crests static; expiration still follows saved frames.
- Map continuous terrain colors to the light palette in generated standalone
  references, keeping current marks legible in both themes.
- Add a themed [river/feeding phase sheet](../viewer-visual-reference.md#river-flow-and-feeding-feedback).

- Add saved-sunlight-driven ground shadows for plants, rocks and animals.
  Morning/evening projections oppose the sun; night and disabled cycles draw none.
  Reduced motion fixes geometry, while sunlight still controls opacity. Batched
  paths draw below the grid and sight overlays without canvas blur filters.
  Add [light/dark shadow specimens](../day-night.md#decorative-object-shadows).

## Compatibility and validation

Existing saved recordings use their current quantity/position/tick fields; no
conversion, new training run or artifact version is needed. The new JavaScript
module enters the runtime asset allowlist for future wheels/source archives.
Refresh the viewer after updating its installed/source assets. No package-version
change or publication is included.

JavaScript regression checks cover deterministic seeking, reduced-motion phases,
quantity clamping/depletion, fixed rock geometry, theme differences, finite small
cells, context restoration, input immutability and absence of RNG use. Controlled
SVG regeneration and light/dark visual inspection use actual renderer functions.
Formatting, packaging and documentation checks complete the development validation.

River/feeding regression checks cover current direction and cell bounds, still
water, confirmed event filtering, absent eaters, reduced motion, bounded cue
retention and identical sequential/random-seek results across chunk boundaries.

Shadow checks cover sun direction/shortening, horizon fade, opt-in/night behavior,
seeking/cycle repetition, fixed reduced-motion geometry, theme ink, batched drawing,
resource depletion, finite small cells and input/context preservation.
