## Changes

The competition preset and viewer module were allowlisted for wheels but absent
from the separately maintained source manifest. Building a wheel from the source
archive therefore failed with `Invalid packaged asset: environments/competition.json`.

The custom `build_py` command now provides the validated `packaging_assets.json`
entries to setuptools' source collector as well as the wheel copy step.
`MANIFEST.in` retains build metadata, source inclusion and exclusions, without a
second runtime asset list. New shipped assets need only the existing allowlist.
The source-archive regression checks every allowlisted member's contents, and
the installed viewer smoke check requests `competition.mjs` over HTTP.

## Compatibility

Rebuild distributions from the updated checkout. Package version remains
`0.0.2.0`; this rollout is not a PyPI publication. Simulation behavior,
viewer behavior, checkpoints, brains and recording formats are unchanged.
Existing published artifacts remain immutable and are not replaced.

## Validation

- All eight packaging tests passed, including fresh source-archive collection.
- The default build sequence completed source archive → wheel locally on
  CPython 3.12, using preinstalled build tools without network access.
- All 67 runtime assets in the wheel matched their checkout bytes. The portable
  wheel contains no host native binary.
- A fresh venv installed the wheel and tqdm from a local wheelhouse. From outside
  the checkout package, isolated Python loaded all 28 presets, ran a five-step
  simulation, restored its checkpoint and read six replay frames. Viewer HTTP
  assets, including the competition module, catalog and replay chunk passed.
- Whole-source Black, clang-format, Prettier and shfmt formatting/checks passed.
- Ubuntu CI execution must be confirmed after pushing; local validation used macOS.

## Rollback

Reverting the shared collector requires restoring every runtime asset in
`MANIFEST.in` as well as the wheel allowlist, including both competition files.
No stored experiment data needs conversion.
