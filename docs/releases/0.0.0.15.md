## Overview

Allows species sharing a brain template to use different update sizes without changing the template or update frequency.

## Changes

- Adds a validated per-species learning_rate_multiplier and an editor-schema entry.
- Sets supplied prey multipliers to 1.0 and predator multipliers to 1.25.
- Carries effective rates through independent controllers, reproduction, warm starts, chaining and checkpoints.

## Compatibility and migration

Missing multipliers default to 1.0. New environment settings apply to new experiments; checkpoint resume keeps stored settings. Larger updates do not guarantee better or faster learning.

## Validation

Adds species-learning tests covering all algorithms, isolation, real optimizer steps, invalid effective rates, inheritance and exact continuation.

## Rollout and rollback notes

Set a multiplier back to 1.0 in a new configuration to remove the asymmetry; changing source JSON cannot retune a saved experiment.
