GRPO collection restores one group-private world, resets dynamic records and
RNG state per trial, and reuses immutable initial observations. Configuration
is copied once per group; all transient caches are discarded between trials.
Legacy/public checkpoint restore keeps its existing defaults and compatibility.

Compatible independent dense actors can use one optional C inference call with
query-local scratch. Six feedforward policy families are supported, including
MAPPO's separate actor/critic and masked PPO's existing action distribution.
Sampling and pending transitions remain per animal in original order. Frozen
compatible policies in trial worlds also batch their forward passes.
Q-learning, QR-DQN, recurrent, random, legacy/custom and unavailable-extension
cases retain scalar decisions. No weights or optimizer state are shared.

There is no change to numeric precision, actions, observations, update cadence,
RNG streams or artifact formats. Older API-2 extensions fall back until rebuilt.
No viewer migration, preset change or package-version bump is introduced.

## Validation and measurement

- Full native-enabled Python suite: 605 tests, 22 skipped; all executed tests
  passed. Python fallback suites: 53 tests, five skipped; executed tests passed.
- CPython 3.13 native build and 34 focused tests passed; CPython 3.12 build passed.
- JavaScript: 107 passed; six viewer appearance sheets regenerate identically.
- Documentation/source tooling: 27 passed. Whole-source Black, clang-format,
  Prettier and shfmt formatting/checks passed.
- Matched groups/checkpoints cover all nine algorithms, mixed masked/recurrent/
  centralized trial policies, mutation/births, terrain, day/night phases, resume
  and run chaining. Chunked binary/XZ replay/activation bytes match references.
- Five-sample component benchmarks show 1.12× isolated GRPO collection and
  1.07× isolated MAPPO decision speedups. GRPO training improves about 4.9% in
  elapsed time; other whole-run cases are near neutral, including a 0.3% slower
  mixed recording. No general peak-RAM reduction is claimed.
- The mixed recording retains exactly 202,676 compressed replay bytes. Raw data
  stays ignored; the maintained benchmark runner and workflow guide provide
  reproducible controls and the complete tables.

- Literal pre-change source comparisons also matched per-step state and canonical
  binary/XZ replay hashes in 12 cases: all nine algorithms plus competition,
  meandering-river and day/night presets.
- Strict documentation build and homepage/visual/link audits passed: all 821
  guide/source pages were reachable, with zero errors across 71,523 references.
  Content-click routes cover 258 public guide pages and 99 maintained visuals.

## Rollback

Use the fresh-world reference collection path and scalar actor inference.
Existing checkpoints, brains and recordings need no conversion.
