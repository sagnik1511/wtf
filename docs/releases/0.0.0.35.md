## Configuration changes

Updates the maintained river-crossing, highlands and enclosed-valley JSON files
in place and removes duplicate `_calibrated.json` presets. River and valley
presets lower maintenance and predator attack costs; highlands increases opening
energy within the existing caps. Reduced movement costs and proximal physical
mating checks remain. Model signatures, reward rules, maturation, cooldowns,
health and starvation damage are unchanged by this configuration update.

Higher opening energy is also supplied to newborns. This is an energy-budget
choice, not an implementation of learned improvement or health recovery.
The calibration utility supports scalar measurement output and captured
configurations without mandatory replays or model archives.

## Compatibility and validation

Configuration validation checks supported values and model contracts. Geography
and lifecycle checks cover proximal gates, population accounting, source
isolation and exact continuation. Runtime physics and viewer formats are
unchanged; no migration or additional dependency is required.

## Adoption and rollback

Use the maintained JSON paths for new invocations. Saved recordings keep their
captured configuration. Recover earlier constants from Git or a captured config
when needed. Current calibration recommendations are maintained separately from
this historical implementation record and do not rewrite existing runs.
