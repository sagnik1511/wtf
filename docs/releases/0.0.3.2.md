## Overview

Stock V7 PPO and masked-PPO training avoid repeated per-sample Python work while
preserving private actor/adapter learning and exact recorded playback data.

## Changes

- Prepare immutable evidence features once per owning rollout update in FP64 buffers.
- Fuse physical-network forward/backward, late residuals and both gradient blocks
  in an optional native CPU minibatch with ordered arithmetic.
- Preserve Python KL acceptance, shuffle and optimizer/auxiliary commits; retain
  reference execution for missing extensions and custom hooks.
- Remove verbose compact movement/scent inspector text, retaining the movement
  plot and a small scent compass with strength/freshness gauges.

## Compatibility and migration

No observation, weight, checkpoint or replay format changes; V1–V7 remain
supported. Rebuild optional CPU kernels and start a new Python process to use the
new entry point. Existing saved checkpoints remain resumable. Old native builds
fall back rather than dropping the adapter. No CUDA support, package-version
change, commit, tag or publication is implied.

## Fixes and optimizations

Independent `wtf-reviewer` validation verified ordered native actor/adapter
gradients, final-policy masks and KL-gated commits. Class-level actor and adapter
optimizer overrides and wrapped class objectives now retain reference execution. Invalid feature buffers are
rejected before gradient writes and released on failure. Exact checkpoint/work/
replay comparisons passed. Matched local CPU tests measured approximately 2×
first-episode and 1.71–1.78× published-evidence training speedups; peak RAM remained
broadly similar. The requested inspector cleanup preserves the visual bearing and
strength/freshness gauges. No unresolved review finding remains.

## Validation

The full Python suite passed 851 tests (29 skipped), and all 195 JavaScript tests
passed. After final hook hardening, 15 focused Python tests passed. Additional coverage checked all fourteen learners with V7 movement,
blended scent and both consequence-input scopes enabled. Independent review
passed 15 focused Python tests, 15 JavaScript tests and scoped Pylint 10/10;
stock dispatch called the kernel while custom optimizers used reference execution.
Twelve policy/source combinations matched exact actor/head gradients, metrics and
complete updates. All 28 benchmark records, paired full checkpoints/work counts
and compressed replay chunks were verified. All-source formatting, full
maintained-source Pylint, portable wheel/sdist and strict Twine checks passed.
Documentation validation covers regenerated controlled visuals, site links and
homepage access. No additional-OS or CUDA execution is claimed.

## Rollout and rollback notes

Existing V7 commands need no configuration changes. Reverting the native fast
path requires no artifact conversion. Rebuild/install CPU kernels from the same
source version; an already-running Python process retains its loaded extension.
