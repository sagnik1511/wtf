## Overview

Reduces repeated replay data with chunk-local keyframes, field deltas and optional gzip while preserving recorded values.

## Changes

- Adds lossless animal/resource field updates and a complete keyframe at each chunk boundary.
- Adds shared Python readers, a JavaScript decoder and native compact HTTP delivery with full-frame compatibility for older clients.
- Adds verified conversion of completed recordings and defaults new replay output to delta plus gzip.

## Compatibility and migration

Plain snapshot arrays, delta chunks and compressed chunks remain readable by the new readers. Older servers/viewers need an upgrade to decode compact files; active recordings must not be converted.

## Validation

Adds codec, cross-language, compression, conversion-failure and HTTP-negotiation tests, and checks unchanged recorded world/learning data.

## Rollout and rollback notes

Preserve original data until a conversion is verified. Choose snapshot/plain output for tools that require the old serialized representation.
