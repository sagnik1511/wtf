## Overview

Developer-agent instructions now require formatting all maintained source files
after each code-changing update, followed by formatter checks and relevant tests.

## Changes

- Black for Python; clang-format for C/C++ and CPython extension headers/source;
  Prettier for JavaScript/CSS/HTML/maintained JSON; shfmt for shell scripts.
- Include tracked and new non-ignored source files, with generated outputs,
  dependencies, results and caches excluded.
- Preserve formatter settings, shell dialects and behavior. Missing or failed
  tools must be resolved or explicitly reported. Repeat after subsequent fixes.
- Documentation-only updates retain link/asset validation requirements.

## Compatibility and migration

Agent/developer documentation only. Future development updates follow the
[formatting workflow](../development.md#mandatory-formatting). It requires the
corresponding formatter tools in the isolated development environment.

## Validation

Local documentation links/anchors, rollout navigation and whitespace checked.
No runtime code or formatter dependencies changed in this instruction update.
