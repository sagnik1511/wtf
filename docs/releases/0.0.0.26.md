## Overview

Adds rare weight variation when training animals reproduce, letting descendants
explore small inherited policy/value changes alongside ordinary RL learning.
The parent is unchanged. Mutation choices are deterministic for seeded births
and have their own RNG stream, preserving physical/action random streams.

## Changes

- Adds per-species mutation configuration to all presets: enabled, probability
  `0.0001` per birth, at most three distinct matrix weights and Gaussian noise
  standard deviation `0.005`. Biases are excluded; zero/disabled settings skip
  mutation. Settings are strictly validated and included in the editor schema.
- Samples 1 through the configured maximum parameter count only on rare selected
  births. Matrix traversal is skipped on ordinary births; no full list of all
  parameter positions is allocated. Noise has an absolute, not percentage, scale.
- Resets optimizer moments, counters, baseline, pending experience and memory
  for mutated children. Synchronizes Q/QR-DQN targets and GRPO reference weights.
  Retains inherited learning rates and Q exploration levels. Update accounting
  uses the reset child's counter as its new baseline.
- Applies the rule to all nine training algorithms and fictional GRPO newborns.
  Trial mutations use independent policies and cannot alter real controllers or
  counters. Evaluation and random-mode offspring keep frozen inherited weights.
- Tracks direct mutation flags, changed-weight counts and biological lineage
  mutation counts in animal state, binary replays and checkpoint restoration.
  A `mutated` event links parent and child. CSV/summary metrics, telemetry,
  behavior analysis and selected champion provenance expose relevant counts.
- Displays mutation lineage in the inspector, including between brain diagnostic
  samples, without adding playback delays or weight arrays to replays.
- Adds the [mutation guide](../mutation.md) and reconciles the prior rollout
  with its existing implementation commit.

## Compatibility and migration

Old configurations/checkpoints without mutation settings restore with the feature
disabled and zero lineage counters. New presets enable the rare defaults for new
training runs; older saved runs keep their original configuration. Model formats,
signatures and warm-start commands remain compatible. A model imported into a
new run keeps artifact ancestry while its new biological family tree starts fresh.

Checkpoint/replay animal records gain scalar lineage fields and metrics gain
mutation counts. CSV headers add `<species>_mutations`; current readers continue
using named columns. Existing binary field tables and codecs handle the additions.
No package, model-size, reproduction cost, health threshold or recording-cadence
change is required. Older simulation code may reject new animal fields; preserve
a matching runtime when continuing a new checkpoint after a rollback.

## Validation

Passed **289 Python tests** and **31 JavaScript tests**, plus viewer module syntax,
configuration/schema field checks, documentation links and Git whitespace checks.
Tests force mutations to cover all algorithms rather than depending on a rare
chance. Coverage includes sparse matrix-only changes, untouched parents/biases,
independent randomness, zero-effect/no-op cases, synchronized targets/references,
optimizer resets and update accounting, unmutated descendants of mutated parents,
frozen evaluation, GRPO trial isolation, readable metrics, champion provenance,
legacy restores and exact JSON/binary continuation through subsequent births.
Forced-event binary replay frames also pass the JavaScript decoder unchanged.

These checks establish integration behavior, not improved ecosystem fitness.
At the default probability, experiments can have no mutation events.

## Rollout and rollback notes

Start a new training run to use the updated preset. Disable mutation or set its
probability to zero for a control. Existing exact resumes retain saved settings;
compatible champion weights can seed a new mutation-enabled experiment. Keep
pre-mutation and descendant champions for controlled frozen evaluations when
assessing benefits rather than relying on a single divergent trajectory.
