## Overview

Establishes the Python ecosystem simulator and a separate JavaScript viewer. Experiments run headlessly and write bounded replay chunks for later inspection.

## Changes

- Adds independently learning Q-network prey and predators, resource regrowth, obstacles, feeding, combat, health and starvation.
- Introduces complete JSON environments, strict configuration validation, seeded runs, metrics and resumable learning checkpoints.
- Adds saved-run discovery, chunk seeking, agent inspection and emphasized kill events in the read-only viewer.

## Compatibility and migration

This is the initial data and CLI baseline. Metrics-only results without playback frames cannot be rendered; create a new recording to use the viewer.

## Validation

Initial simulation, recording and playback tests cover world mechanics, seeded behavior, checkpoint continuation and chunk loading.
