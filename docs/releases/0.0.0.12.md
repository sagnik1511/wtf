## Overview

Makes experiment folders self-contained and makes source-model choices explicit at invocation time.

## Changes

- Stores champions beneath each experiment and numbered run, with indexes that locate its archived model files.
- Adds --brains-from, --brain-run and per-species --brain selectors; retains optional shared-library workflows.
- Records resolved model paths and provenance while rejecting incompatible models before creating results.

## Compatibility and migration

Warm starts load weights into fresh controllers, whereas --resume restores an exact saved experiment. Moving results must preserve the indexed champion directory structure.

## Validation

Extends library tests for CLI selectors, latest/specific source runs, relocated archives, missing files and incompatible models.

## Rollout and rollback notes

Older shared-only tooling may not resolve run-local archives. Keep each experiment index and its models together during migration or backup.
