## Overview

Each lineage candidate previously built diagnostic dictionaries and calculated
reporting rates even when no champion changed. Existing families also received
a freshly constructed, discarded default dictionary on every accounting update.
These allocations are now deferred until needed.

## Changes

- Founder-family counters are allocated only for a previously unseen root.
- Rank comparisons omit metadata. Final lineage winners receive the same detached
  diagnostic values as before, with the same founder ordering and tie-breaking.
- Full rank requests build metadata once for the strongest family, rather than
  for each intermediate strongest family.
- No cache, persistent state or dependency is added. This path is shared by all
  algorithms, irrespective of the configured champion selection criterion.
- Reconciled rollout 0.0.1.4 with verified implementation commit `65345bf`.

## Compatibility and migration

No configuration, precision, learning cadence, observation, RNG, checkpoint or
replay format changes. FP64 arithmetic and existing FP32 model storage remain.
Existing recordings and models need no conversion. Restart training processes
to adopt the Python changes; the viewer requires no changes.

## Validation

- Seven alternating accounting/ranking samples, each with 500 passes over 60
  animals (48 prey, 12 predators, two-founder descendants), comparing against
  `65345bf`: medians 0.15828 s before and 0.09859 s after (37.7% less time).
  This probe excludes model learning, observation and winner model snapshots;
  it does not establish an end-to-end training speedup or lower peak RAM.
- Exact complete-checkpoint comparisons: ten 40-step, seed-42 presets covering
  DQN, PPO, A2C, REINFORCE, GRPO, recurrent PPO, QR-DQN, Maskable PPO, MAPPO
  and mixed A2C/GRPO meandering river. Every before/after state matched.
- Focused lineage/cache/promotion suites: 31 tests passed. Added checks cover
  founder ties, rank-only parity, detached metadata and metadata calls only for
  winners. Existing suites cover births, dead ancestors and exact continuation.
- Python suite: 409 tests passed; seven HTTP socket tests excluded because this
  sandbox blocks localhost binding.
- All 50 JavaScript viewer tests passed.

Raw local probe inputs/results are ignored under `.cache/lineage-optimization/`.
No experiment results were converted or removed.

## Rollout and rollback notes

Pending local changes; no commit or tag created. Reverting the Python changes
