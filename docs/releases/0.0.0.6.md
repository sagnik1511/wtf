## Overview

Adds policy-gradient alternatives to the original Q-network implementation while retaining independent per-animal controllers.

## Changes

- Adds PPO, A2C, episodic REINFORCE and experimental GRPO dispatch, policy networks and Adam optimization.
- Adds algorithm presets, mixed Q/PPO environments, algorithm-aware checkpoint restoration and policy diagnostics.
- Adds tqdm training progress and CLI controls; the viewer remains separate from simulation.

## Compatibility and migration

Install the declared tqdm dependency inside the project virtual environment. Model architecture and algorithm must match when restoring or reusing weights. GRPO uses matched simulator trials; REINFORCE collects full episodes.

## Validation

Adds PPO numerical-gradient and rollout tests, policy-algorithm tests, matched-trial checks and progress-output checks.

## Rollout and rollback notes

Older Q-only code cannot restore policy-gradient controllers. Keep a compatible source revision with PPO/A2C/REINFORCE/GRPO results.

Inspect this revision with `git show --stat 08e2e5b`. Version numbers in this
history are documentation identifiers; they do not imply Git tags or deployment.
