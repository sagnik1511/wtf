## Behavior

Cached inspector SVGs and prediction bars previously retained dark-palette paint
values when the interface switched to light mode. Shared CSS color references
now recolor radars, target legends, prediction history, activation units and
archived-model sensitivity/route charts immediately, without seeking, rebuilding
cached charts or advancing the replay. Dark fallback colors are preserved.

Recorded previews now have matching light exports. GitHub uses picture media;
the documentation build resolves nested asset paths and selects images using
its explicit palette toggle. Original GIF URLs remain dark/legacy fallbacks.
Light previews use 128-color animated WebP to limit duplicate media size. Both
variants show matching steps and duration; no filter changes recorded pixels.

Standalone inspector, map and viewer specimen SVGs receive a shared light
presentation palette. Explicit theme/daylight comparison sheets stay fixed.

## Distribution and compatibility

Package version remains `0.1.0`, independently of this internal rollout number.
Metadata links to the deployed documentation, and packaging instructions cover
isolated TestPyPI uploads and installs. The selected publication target is
TestPyPI only; production PyPI publication is separate. Upload status remains
pending until authenticated upload and index verification succeed.

No simulation, brain/checkpoint/replay format, policy, RNG or numerical behavior
changes. The optional WebP encoder is documentation tooling, not a runtime
Python dependency. Refresh the viewer page to load updated JS/CSS; existing
recordings remain compatible.

  strict site build and built link audit are run before handoff.
