each implementation commit. Detailed operational guides remain in their existing
locations; the project README gains a link to the hub.

## Rollout and rollback notes

After the documentation commit exists, record its actual hash and commit date in
a subsequent documentation update and change this entry to Committed. Recording
that known hash does not require a new application rollout. If changes are split
across implementation commits, record the full range or split the release record.
Reverting this documentation does not modify saved experiments.
