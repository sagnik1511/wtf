## Overview

Adds a repository-wide systems-paper draft aligned with Nature Machine
Intelligence's Article structure, with an editable supplementary space for
future controlled ecological observations. Standard `article.cls` and numerical
citations follow the journal's accepted manuscript guidance. This is an
author-prepared draft, not an official journal class or a submission claim.

## Changes

- Unheaded introduction, Results, Discussion and detailed Methods; a 131-word
  abstract; 13 primary method/platform references; data/code availability and
  author-declaration fields. Ecological results remain explicitly unfilled.
- Five main vector figures explain runtime ownership, geography and the top-k
  observation layout, two-parent parameter crossover and founder-family
  membership, artifact access semantics, and historical engineering measurements.
  One Methods controller table completes the six main display items.
- Engineering plots read exact timing/byte values from included CSVs. Timing
  campaigns and independent storage fixtures keep their original scope; no raw
  replicates, error bars or ecological outcomes were invented. Exact tables,
  future-study registry/outcome template and evidence inventory are supplementary.
- Reproducibility protocol covers frozen/fresh/random controls, seed-level
  replication, mutation/evaluation differences, budgets, censoring and coverage.
- Sagnik Roy's provided name, linked GitHub/LinkedIn profiles and phone number
  remain editable in a separate author file. Affiliation, email, funding,
  competing interests and archive fields remain to confirm or complete.
  AI drafting assistance is disclosed in Methods.
- The former pending TMLR styling is replaced; its unused vendored style and
  bibliography files are removed. Standard TeX distribution packages provide
  formatting. Build guidance links current journal requirements.
- Generated outputs include a preview PDF, a portable source archive, and a
  single-text-file export with bibliography inlined. Package/build caches remain
  ignored. Reconciles committed 1.16 documentation with `6e354d3`.

- Build portability fix: replaces the optional `placeins` float barriers with
  built-in page boundaries, avoiding a missing `placeins.sty` failure in the
  desktop preview compiler.

- Line numbers are disabled by default; an explicit TeX switch enables review
  numbering and loads `lineno` only when needed.

## Compatibility and migration

Paper/documentation only. No simulation, learner, result format or preset changes.
The normal editable entry point is `docs/paper/main.tex`; generated exports must
be rebuilt after edits. The flattened export still needs the included chart
CSVs and retains convenience macros to remove for final production submission.
Public metadata, declarations and future evidence remain to complete.

## Validation

The manuscript compiles with Tectonic and the desktop editor’s compiler after
the missing-package repair. Rendered pages and enlarged figures were
reviewed, and overlapping diagram text was corrected. No overfull boxes,
undefined references/citations or duplicate table destinations remain. The default build emits a benign bibliography underfull-line warning. Enabling
review line numbers may also emit a legacy lineno package-comment encoding warning. Exact CSV values match the manuscript's
historical measurements; five figures, one main table and 13 citations resolve.
Both the modular archive entry point and flattened export are independently
compiled from a clean source copy. Author profile and phone links are checked
in the PDF. Markdown links/assets and Git whitespace are checked. No runtime
suite or ecological experiment is run for this documentation-only update.
