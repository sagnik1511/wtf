## Overview

Two separate strong-predator river presets provide an architecture comparison:
`river_crossing_strong_predator.json` keeps prey `[16]` and predators `[128, 64]`;
`river_crossing_strong_predator_deep.json` uses deeper networks for both species.
Both give predators a significantly longer view on the existing river map.
It is an experimental advantage in capacity and perception; improved hunting
outcomes have not been established by long training.

## Changes

- Based on `river_crossing_ppo.json`. The standard strong-predator preset keeps
  prey `[16]` and predators `[128, 64]`.
- The separate `_deep` preset uses prey `[64, 32, 16]` (three hidden layers)
  and predators `[128, 96, 64, 32]` (four hidden layers).
- Per-animal deep networks contain 7,160 prey parameters and 29,768 predator
  parameters, including biases and the combined action/value output.
- Predator base sight radius increases 8 → 14 and directional water bonus 3 → 6.
  Water extension still depends on water cells along the ray; walls occlude.
- Prey retain sight 6 + up to 3 across water.
- Map, body costs/health, learning settings, rewards, reproduction and replay
  settings match the original PPO river preset. Both initially used 32-input
  version 2; [rollout 0.0.1.7](0.0.1.7.md) subsequently opts both into k=4
  (68 inputs), requiring matching top-k weights.

## Compatibility and migration

No engine changes or dependencies. Choose the new JSON explicitly using the
[documented command](../geography.md#river-crossing-with-stronger-predator-capacity).
Start fresh or load terrain PPO champions matching the exact network depths
and top-k setting. Standard enhanced-preset models are incompatible with the
deep variant, even when their input count is already 68. Existing
checkpoints still resume their saved architectures; this preset changes new
experiments and does not expand old weights or edit saved runs.
Existing replay formats and viewer behavior are unchanged. More sight and larger
networks increase work per predator; no runtime or ecological improvement is claimed.

## Validation

- Both standard/deep JSONs validate and continue identically after checkpoint
  restoration. A normalized comparison confirms only names, template selection
  and network sizes differ between variants.
- All-example validation and enhanced-river binary replay checks: 2 tests passed.
- Compared against the preceding enhanced river JSON: only network widths,
  the prey template name/reference and descriptive text changed. The deeper
  configuration is now preserved in its own `_deep` JSON. Sight, k,
  learning settings, physics, rewards, reproduction and recording are retained.
- A 66-step seed-100 smoke run exercised PPO updates for both species. A
  binary/XZ checkpoint after step 64 resumed with exactly matching final state.
- PPO and enhanced-river binary replay checks: 20 tests passed.
- Earlier geography and directional water-vision suites: 27 tests passed.
