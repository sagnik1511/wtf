## Overview

Adds a maintained two-hilltop environment connected by a narrow low dry bridge.
The shared crossing is traversable without swimming, with optional water routes
around it under existing locomotion rules.

## Changes

- `land_bridge` preset: ordinary PPO for both species, existing calibration,
  dry founder/resource placement and configured capture for every episode.
- Packaged 40 × 28 map with a three-cell-wide crossing, shallow shores and
  deeper still water. Both landmasses rise to elevation five through one-unit
  terraces; the bridge stays at zero. No new physics, actions or access restrictions.
- `land_bridge_behaviors` companion preset combines local social sensing,
  episode-published general/context consequence observations, visual history,
  blended scent, day–night modifiers and learned same-species challenges.
  All playbacks are retained and private policy weights remain independent.
- Actual-map preview, geography guide and packaged asset allowlist entries.

## Compatibility and migration

Additive preset only. Existing presets, model signatures, checkpoints and replay
readers are unchanged. The behavior variant adds input blocks and a challenge
action, so start fresh rather than loading simple-preset brains. Use a new run to select this geography; existing saved
recordings retain their own maps. The source checkout supports the preset now;
the already published package does not include this pending addition.

## Fixes and optimizations

Independent preset review verified a connected dry route, a three-cell-wide
bridge cut separating two landmasses, still water, dry founder/resource placement,
packaged asset registration and byte-for-byte preview regeneration. The review
also verified elevation-five hilltops on both sides, a zero-height connector
and one-unit-or-smaller dry cardinal slopes with connected climbable routes.
The existing prey/predator uphill energy costs remain unchanged. The review
also corrected an outdated preset/map count in the geography introduction by
removing the brittle numeric total. No runtime
defect or optimization was found in this additive preset change. Existing
simulation and viewer code are unchanged; long-run population sustainability
and policy behavior have not been evaluated for this map.

Companion-preset review verified that both ordinary PPO brains consume the
enabled social, combined consequence, movement-history and blended-scent input
blocks, with episode-boundary consequence publication through the existing
runner. The added inputs and challenge actions produce distinct model signatures;
the fresh-brain migration note is required. Existing reproduction, mutation,
learner settings and full-playback capture remain inherited from the simple
preset. No new runtime logic or performance improvement is claimed.
