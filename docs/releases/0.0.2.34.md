## Overview

Opt-in V5 expresses spatial inputs as forward/right and exposes immediate
attack/eat/swim opportunities. Ordinary PPO remains unmasked, and V1–V4 retain
their established input semantics and compatibility.

## Changes

- Rotate target/mate offsets, current, personal visual history and local scent.
- Append three affordance values after consent, before optional feature blocks.
- Keep independent brains, physics, top-k, proximal reproduction and mutual consent.
- Decode recorded V5 into north-up inspector/board diagrams; update raw labels,
  opportunities, private weight explanations and controlled theme-aware visuals.
- Ship `seaside_150_v5`, retaining the V4 preset, and a compact matched comparison
  helper with separate greedy/stochastic frozen holdouts.

## Compatibility and migration

V5 adds three inputs and changes spatial meanings. Start with fresh compatible
weights; versioned signatures reject V4/V5 substitution. Checkpoints restore
their saved versions. Replay codecs are unchanged; V5 requires the current
viewer. No old recording, model or preset is converted. No package version,
commit, tag or publication is created.

## Fixes and optimizations

Independent `wtf-reviewer` review verified versioned widths, recorded-heading
projections, native/reference observations, exact checkpoint continuation and
unmasked ordinary PPO. Fixed V5 scent labels to preserve arbitrary species
names. Frozen stochastic evaluation now allocates one private RNG per animal
while preserving exact choices. Cardinal scent permutations are precomputed;
no runtime speedup is claimed.

## Validation

Local validation covers the full Python and JavaScript suites, all maintained
source formatters, Pylint (10/10), portable wheel/sdist builds and strict Twine
metadata checks. Independent review passed 26 focused Python tests, 14 JavaScript
tests and 40 fixed-action phases across five presets with equal world state,
RNG, rewards and events. Controlled V4/V5 viewer specimens were rendered in both
themes; generated documentation is checked for local links and homepage routes.
The matched comparison stores compact local summaries; ecological outcomes stay
outside release documentation and are not a software performance guarantee.
No additional OS matrix or GPU execution is claimed.

## Rollout and rollback notes

Use the explicit V5 preset or set version 5 on selected templates. Return to a
matching older preset/brain for older input semantics. Keep the current reader
for any V5 artifacts already produced.
