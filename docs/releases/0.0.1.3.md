## Overview

Feedback needed review across the expanding set of maps and controllers without
introducing map-specific or algorithm-specific physical reward formulas. The
existing shared event/cost rules were checked against all 24 presets and nine
controllers. No missing or double-applied reward was found in the reviewed
paths; runtime code and reward tuning remain unchanged by this rollout.

## Changes

- Adds a generic contract regression covering 216 preset/controller combinations
  with renamed species, existing terrain/placement, living-cost feedback and
  terminal starvation penalties/transition flags. Small controlled populations
  and valid resting choices isolate feedback delivery from exploration.
- Verifies individual feedback for ordinary controllers and the documented
  species-mean MAPPO training adapter while recorded feedback stays individual.
- Documents the shared reward formula, physical terrain consequences, actual
  coefficient scales, GRPO trials, optional legacy fields and offline coverage.
- Separates accounting correctness from sparse mating feedback, limited planning
  horizons, hidden mating eligibility and ecological calibration.

## Compatibility and migration

This rollout changes tests and documentation only. No preset values, runtime
formula, learner loss, native kernel, observation/action signature, RNG behavior,
checkpoint or replay format changes. Existing pending lineage work remains
separate and preserved. No installation, conversion or restart is required.

## Validation

All 42 focused feedback/reproduction/hit/geography tests passed with the default
native backend and again with `WTF_KERNELS=python`. The new matrix independently
checks 216 combinations, each for a normal and terminal transition. Existing
tests cover successful/failed consent, both parents' costs, partial/shared hits,
terrain/water/drowning effort, masks, trial isolation and offline accounting.

These are deterministic short contract checks, not training/calibration
experiments or evidence of learned behavior. MAPPO intentionally averages a
death penalty across its species; this review does not redefine that objective.

## Rollout and rollback notes

See the feedback review for the focused command and tuning boundaries. New
geographies should reuse the same physical-event contract; species tuning stays
in JSON. The review/test files can be removed without changing the simulator.
No commit, tag or package-version change is created by this record.
