## Overview

Three additional independent policy implementations are available through JSON
brain templates. Maintained environment presets are unchanged. Discrete SAC
adds private replay and twin Q critics; TRPO adds a constrained natural-gradient
actor; LSTM PPO adds hidden/cell memory to the existing recurrent learning path.
No ecological performance improvement is claimed from implementation alone.

## Changes

- Add strict Python/schema definitions, dispatch and distinct model signatures.
- Integrate exact checkpoints, warm starts, species/sex champions, crossover,
  mutation, fresh newborn training state and GRPO trial-memory isolation.
- Preserve categorical-probability diagnostics and actual sampled activations.
  Archive explanations show actor routes separately from critics and explicitly
  use zero prior memory for LSTM. Viewer labels distinguish LSTM from GRU.
- Document all template fields and selection through a local environment copy;
  add a theme-aware block diagram linked from learning navigation/catalogs.
- Remove repeated TRPO direction slicing/distribution work, SAC gradient-list
  slicing and LSTM cell-activation calculations. Document remaining native
  opportunities without claiming unmeasured speedups or adding a new kernel.

## Compatibility and migration

No artifact codec, physical rule, reproduction radius or existing preset changes.
New algorithm identifiers need this runtime; old weights cannot be relabelled to
bypass architecture checks. SAC checkpoints add target critics/replay, TRPO
stores separate networks/policy counters, and LSTM checkpoints store both memory
vectors and pending sequences. Current scalar/native helpers remain available;
no new dependency, GPU path or compiler requirement. No package version bump or
publication is part of this rollout.

## Validation

Mathematical checks cover SAC expectation/actor derivatives, terminal versus
truncated targets, TRPO conjugate gradients/Fisher products/accepted KL and actor
rollback, and two-step LSTM BPTT with nonzero hidden/cell state. Shared algorithm
fixtures include feedback across all presets, multiple species, birth/mutation,
activations and archive inference/input-gradient parity. Lifecycle tests cover
pending decisions, buffered updates, warm starts, checkpoint continuation,
diagnostic transparency and private LSTM memory in GRPO trials.

The source archive builds a pure-Python wheel offline. A fresh installed
environment outside the checkout loads all 29 presets, serves viewer HTTP assets
and saved chunks, restores recovery state, and executes each new policy through
the CLI with checkpoint/explanation verification. Final validation passes: 682 Python tests (22 optional documentation-dependency
skips), 125 JavaScript tests, 41 Python-fallback policy/lifecycle checks and 27
explicit documentation/source tests. Black checks 161 Python files, clang-format
four native files, Prettier 93 web/JSON files and shfmt two shell files. The built
site checks 903/903 reachable documentation pages with no local link/asset/anchor
errors. Complete JSON template/selection recipes execute successfully. No timing
benchmark or new C kernel is claimed by this inspection-driven hotpath review.

## Rollout and rollback

Select a complete new template following [the guide](../additional-policies.md);
no environment is switched automatically. Existing presets stay usable with
older runtimes. Keep this runtime with new-policy artifacts to restore them;
reverting the source does not make an older dispatcher understand new identifiers.
