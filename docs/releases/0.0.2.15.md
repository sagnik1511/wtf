## Overview

LSTM PPO can be selected with `wtf run lstm_ppo` without manually creating a
local configuration. `environments/lstm_ppo.json` is an allowlisted runtime asset,
so the preset is available from a checkout and future wheel/source distributions.

## Configuration and compatibility

Both species use LSTM PPO with recurrent size 16 and sequence length 8. World,
body, rewards, reproduction, observation layouts, MLP head sizes and artifact
retention are copied from the current ordinary-PPO preset. The population starts
at 64 prey and six predators; mating radii remain 2/3 and horizon 1,500 steps.
Lifespan champions chain between episodes. Full playback captures the final two
scheduled episodes. This is a starting profile, not a new ecological calibration
claim. Existing presets, algorithm implementations and saved results are unchanged.

Current source is required; published 0.0.2.9 predates LSTM support. PPO/GRU
champions are incompatible with the LSTM signature. No package-version change,
publication, artifact conversion or migration is part of this update.

## Validation

Preset/schema validation, short-name discovery, native LSTM construction and a
short CLI training/recovery/playback check are performed, alongside packaging,
feedback and documentation checks. All maintained source formatters run before
final validation. See the development handoff for the executed results.
