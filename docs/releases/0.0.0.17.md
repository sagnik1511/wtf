## Overview

Adds configurable survival-plus-kill selection, a DQN-for-both-species preset, and lower-overhead Q training and controller cleanup.

## Changes

- Adds a balanced predator criterion with a capped survival bonus after the first kill, scoring-policy metadata and old-archive candidate rescoring.
- Adds environments/dqn.json with DQN prey/predators; its current committed preset selects lifespan champions for both species.
- Computes only the selected current Q output during replay loss, precomputes action indices and refreshes target arrays in place.
- Releases dead founders after terminal learning/champion capture, preserves cumulative update counts and legacy retention, and skips unused GRPO scans.

## Compatibility and migration

The GRPO preset opts into balanced selection; other configured criteria still apply. The default balanced bonus can leave kill and balanced winners identical. Archive rescoring considers only saved candidates and does not recover unarchived models.

## Validation

Recorded validation: 200 Python tests passed. Reference updates check exact DQN state, replay wraparound, target refreshes and restoration; lifecycle checks cover terminal feedback, buffer release and chaining. No profiler or benchmark was used for this pass.

## Rollout and rollback notes

Existing training processes retain imported code and need a new invocation to adopt changes. Keep legacy retention support for older checkpoints; preserve original model artifacts when changing selection policies.
