Repeated age/rank improvements can capture identical champion weights between
optimizer updates. The champion book now compares exact packed FP32 buffer bytes
and the model signature, reusing an immutable detached snapshot when unchanged.
Source/rank metadata remains current. The bounded cache uses weak controller
references, discards non-winners on the next pass and never enters checkpoints.
Legacy FP64 models retain the uncached path. Comparison bytes are allocated lazily and add four bytes per
cached parameter only after reuse; changed optimizer counters skip byte checks,
while equal counters still require exact comparison; this is not a claim of lower steady-state RAM for every model.

Path contests reuse one lazily constructed live occupancy set for their phase,
updating it after movement and deaths. Original target choices, conflict order,
terrain checks, effort, RNG and viewer events remain unchanged.

No artifact, action signature, precision or package-version change is introduced.
No new native kernel is needed for these ownership/copy optimizations. The
separate [top-k kernel rollout](0.0.2.3.md) records its exact-parity requirements
and matched measurements.

## Validation

- Full Python suite: 590 tests, 22 skipped; all executed tests passed.
- JavaScript suite: 107 passed; all six viewer appearance sheets regenerated
  byte-for-byte from their current drawing functions.
- Dedicated snapshot/occupancy plus competition tests: 26 passed on the Python
  fallback, alongside the native-enabled full suite.
- Before/after full-checkpoint trajectory hashes matched across all nine
  algorithms (two short runs each), plus fixed-seed competition and mixed-terrain
  presets, with both native and Python backends.
- Dedicated checks cover current rank/source metadata, unreported parameter
  edits, signed zero, signature changes, legacy precision, weak controller
  ownership, bounded pruning, randomized phase equivalence and retreat into
  cells vacated by earlier movement or competition deaths.
- Controlled operation counts reduced detached model captures from 63 to six
  in a 20-step PPO fixture and full animal-list passes from five to three for
  three path contests. These are not end-to-end time/RAM measurements.
- Whole-source Black, clang-format, Prettier and shfmt formatting/checks passed.

- Binary/XZ replay chunks, including sampled predictions and activations,
  matched byte-for-byte against uncached/rebuilt references for flat,
  competition and highland fixtures on both backends.
- Strict documentation build, visual-access catalog and local link/anchor audit
  passed; the new rollout remains accessible through the release hub.

## Rollback

Return to uncached champion snapshots and per-displacement occupancy construction.
Existing brains, exact checkpoints and recordings require no migration.
