## Behavior

Tracks health, kills, lifespan and food champions independently for each sex in
every species, with balanced champions for each predator sex. Female/male prey
and predators therefore have four independent model pools. Snapshots still copy
only final winning controllers once per ranking pass. Child crossover and rare
mutation are unchanged; children compete in their assigned sex's pool.

Run-to-run chaining uses each matching group winner. Artifacts live under
`champions/run_NNNN/SPECIES/SEX/CRITERION.json`, with per-group source ancestry.
`--brain prey=lifespan` resolves female/male lifespan champions independently;
`--brain prey:male=kills` targets just males and overrides broad flags regardless
of ordering. `fresh`, exact paths, best/latest selectors and `--brain-run` work
with the grouping. JSON supports `initial_brains` and `champion_selection_by_sex`.
[Model-selection details](../brain-library.md#species-and-sex-selection).

Prey colors are green (female) and blue (male); predator colors are orange
(female) and gold (male). Male bodies also have a light outline. Legend labels
match; species charts retain their species colors. Replays lacking sex fields
keep their original colors rather than displaying invented sex assignments.

## Formats and migration

New library/index format is version 2; artifacts are version 2. Readers accept
versions 1 and 2. Known-sex artifacts initialize only their matching sex, and
explicit mismatches fail. Automatic source loading leaves a missing sex fresh;
explicit requests for an unavailable group fail. Untyped legacy artifacts can
still supply a shared starting model to both sexes. Older source archives remain
untouched; unarchived historical sex winners cannot be recovered from replays.

Checkpoint initialization/provenance and champion books are nested by species/sex.
Old species-wide books retain historical entries with known sex and start other
groups from live controllers. Existing loaded initialization is preserved on
restore. Current JSON/binary resumes retain both groups and do not require source
files. Older readers may not understand these new archive/checkpoint structures.
Start a new training invocation to adopt the changes; refresh the browser for
new colors. A running old process keeps its imported champion implementation.

## Rollback

Keep current readers and preserve new results before reverting archive handling.
The older reader cannot recreate absent sex winners or infer them from aggregate
records. Viewer palette changes can be reverted independently of saved files.
No commit, tag or package release is created by preparing these records.
