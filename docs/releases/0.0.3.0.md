## Overview

V6 assembly and private auxiliary training perform less repeated allocation and
pure computation, preserving observations, training state and recorded playback.

## Changes

- Compile zero bases, consequence confidence positions and indexed block offsets.
- Reuse bounded immutable scalar, bearing and reconstruction coefficients.
- Use slotted immutable structural plans and fresh per-observation containers.
- Skip zero-evidence auxiliary target decoding/copies under the stock decoder;
  preserve custom target hooks, gradient order and existing KL gating.
- Document the complete V6 input layout with decoder-checked offsets, optional
  block ordering and light/dark target-slot expansion and V5 → V6 data comparison.
- Maintain an isolated benchmark that checks complete state and replay bytes.

## Compatibility and migration

No configuration, observation width/value, weight, checkpoint or replay format
changes. V1–V6 remain supported, brains remain independent and all playbacks are
retained. No viewer runtime change or new kernel is required. Caches are derived
and rebuilt, never serialized. No package version change, commit or publication.

## Fixes and optimizations

Independent `wtf-reviewer` validation found no actionable defects in the scoped
optimization. Reuse bounded immutable V6 coefficient/layout data and skip stock
auxiliary target decoding only for zero-confidence samples. Preserve raw scalar
types, signed-zero coefficients, custom target hooks and per-animal optimizer/RNG
ownership. Exact paired observation/state/replay checks and an independent
23-test regression review passed. No unresolved behavior decisions; detailed
measurements and memory scope are in the linked performance guide.

## Validation

Local full-suite results: 837 Python tests (29 skipped), 192 JavaScript tests.
All-source formatting, full maintained-source Pylint (10/10), portable wheel/sdist
builds and strict Twine validation passed. Independent scoped Pylint also passed.
Documentation validation covers generated catalogs, links, assets and homepage
reachability. Matched local
CPU medians improved semantic assembly 1.57×, first-episode PPO training 1.66× and
published-evidence episode training 1.22×. A retained observation-bank allocation
probe used 40.4% less traced Python memory, not 40.4% less whole-process RAM.
Bit-level encoder, complete checkpoint and compressed replay checks matched.
No NVIDIA or additional OS validation is claimed.

## Rollout and rollback notes

Existing V6 commands need no changes. Restart a running Python process to adopt
new code. Reverting the optimization requires no artifact conversion; do not
change observation version metadata when restoring existing models.
