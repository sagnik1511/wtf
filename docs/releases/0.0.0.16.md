## Overview

Adds timeline-linked species telemetry and reduces checkpoint storage while retaining old checkpoint readers.

## Changes

- Adds bounded per-frame telemetry pages, rolling charts, species filters, prediction samples and spatial-group metrics tied to playback position.
- Adds compact checkpoint envelopes with shared metadata, exact numeric arrays and gzip, plus legacy JSON output and verified conversion.
- Raises predator preset health by 10% and preserves the reproduction threshold fraction.

## Compatibility and migration

Restart the server and refresh the viewer so the telemetry endpoint and modules agree. New CLI checkpoints use .json.gz; legacy plain JSON remains readable. Converters skip active experiments.

## Validation

Adds dashboard cache/view, telemetry, compact checkpoint roundtrip and conversion-safety tests. The checkpoint implementation was checked with the full 187-test Python suite during development.

## Rollout and rollback notes

Older source cannot directly decode compact checkpoint envelopes. Use legacy JSON export before moving resume files to an older engine; copying results does not alter their format.
