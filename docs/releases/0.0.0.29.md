## Changes

Adds root [AGENTS.md](../../AGENTS.md) with project constraints and targeted
verification guidance, plus [project context](../project-context.md) documenting
stable decisions, code navigation, initialization/resume semantics, storage and
common operational pitfalls. Three repo-local skills support repeated saved-run
analysis, simulation/storage optimization and release-document maintenance.
README and development guide link these entrypoints. The skills were authored
with the built-in skill-creator workflow; no global skill installation is needed
to read them directly. Reconciles the preceding documentation rollout with its
existing implementation commit. Shared setup examples now use `/path/to/wtf`;
project instructions require portable paths instead of personal checkout locations.

## Compatibility and validation

Documentation and agent instructions only; no simulation/configuration/data
format changes or runtime packages. Skill discovery depends on the coding client;
AGENTS.md links each SKILL.md for direct use. All three skills pass the
skill-creator validator. Checked local Markdown references, UI metadata, verified
Git hashes, whitespace and absence of personal checkout paths in shared text. Validation-only
PyYAML lives in the ignored `.cache/skill-tools/` virtual environment; runtime
requirements are unchanged. Runtime tests are not needed for this change.

## Rollout and rollback

Future sessions can start from AGENTS.md without chat history. Keep detailed
behavior in existing guides and update relevant context when decisions change.
Remove these instructions/skills and their links to revert; saved results are
unaffected. No commits or tags are created by this rollout preparation.
