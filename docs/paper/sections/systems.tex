\subsection{System Architecture and Artifact Design}\label{sec:systems}
\subsubsection{Ownership and execution boundaries}
Python owns world transitions, controller updates, selection and recording.
The read-only server and JavaScript viewer consume saved artifacts and do not
advance a live simulation or load its optimizer. JSON environments specify
bodies, actions, templates, geography, rewards and experiment settings under
validation. The same template is copied into private animal controllers, not
used as a shared policy singleton. Figure~\ref{fig:architecture} summarizes the
boundaries.

\subsubsection{Derived caches and removal of repeated work}
Observation preparation reconciles authoritative animals and food once per
phase. Separate spatial indexes organize food and both diet groups into buckets.
Each observer's query window retains references to overlapping buckets after
movement; entering/leaving strips update those references. A cached target query
includes observer position, radius/range settings, target revisions and $k$.
Target movement, birth, death and food-presence changes therefore remain visible
even to a stationary observer. Sparse/wide queries can use a direct scan.
Bounded static ray caches follow separate obstacle/visibility invalidation.
Self, health, heading, terrain and readiness remain current rather than reusing
a frozen complete observation. Trial worlds own independent mutable caches.

Other reductions include computing only needed output heads, avoiding unused
backpropagation tapes during inference, reusing gradient containers within an
update, copying only final champion winners, and releasing dead controllers
after terminal learning/capture. These preserve schedules and mathematical
ordering; they do not increase learning frequency to manufacture speed gains.

\subsubsection{CPU kernels and numeric boundaries}
An optional CPython C extension accelerates dense inference/backpropagation,
SGD/Adam, PPO minibatch work, GRU operations, quantile derivatives, perception,
selected flat-world phases, replay helpers and group metrics. Python still owns
scheduling, rules, RNG streams and the public object model. Each native call has
bounded scratch ownership; the extension does not create a shared species brain.
Terrain-specific physics remains Python, and top-$k$ target candidate selection
for $k>1$ retains a Python path rather than the fused nearest-only selector.

New model/optimizer arrays use packed FP32 storage. Activations, reductions,
losses, gradient accumulation and world arithmetic retain the established
float64 behavior. FP32 storage can alter trajectories relative to older FP64
models, so it is not claimed equivalent to that precision change. Exact legacy
resume preserves its recorded precision. Native/reference comparisons are made
at the same storage precision and numerical contract, with fast-math/FMA
contraction disabled where required. This is CPU acceleration, not CUDA or
vectorized GPU support; supported interpreters/platforms and available kernels
are checked explicitly.

\subsubsection{Three different saved artifacts}
\paragraph{Replay for inspection.}
The recorder streams full first frames and sparse absolute-value deltas into
independently decodable chunks. Animal IDs and resource coordinates key entity
updates; masks identify changed fields. Absolute replacements avoid cumulative
numeric drift. Static configuration/geometry and committed-run counts live in
metadata rather than every frame. Sampled diagnostics contain observations and
predictions/counters, not weights or raw training buffers.

Default files use the versioned \code{WTFB} typed codec and XZ compression.
Numeric arrays select lossless widths, repeated strings use a file-local symbol
dictionary, and equal-shape entity records can become field tables and columns.
New chunks reset their delta baseline and dictionary. The browser retains one
decoded world chunk; XZ decompression is performed per requested chunk by the
server. A direct seek can briefly inspect the preceding chunk for event
positions. Lightweight charts and bounded selected-agent histories remain
separate from world-frame retention.

\paragraph{Checkpoints for exact continuation.}
A binary checkpoint contains experiment/world metadata, one controller record
per saved brain and a final internal shared-value table. Each private record
preserves applicable online/target/reference networks, optimizer moments and
variances, replay/rollout/trajectory buffers, cursors, pending decisions,
recurrent/masked/centralized state, counters and RNGs. Experiment state includes
seed generation, selection, lineage and early-stopping progress. The writer
streams detached brains one at a time to a temporary file and publishes by
atomic rename. Loading resolves detached shared values and reconstructs the
whole learning state in RAM; buffers are not fetched lazily from disk.

\paragraph{Champions for warm starts.}
Small JSON artifacts describe criterion, rank, source, model generation and a
reference to a shared binary/XZ blob. SHA-256 names the complete uncompressed
model record, including signature, precision and parameters. Identical encoded
models can be shared across criteria and runs. Configurations are separately
pooled, and export-local identity caches avoid repeating serialization work.
Warm starts copy compatible parameters into fresh private controllers; they do
not restore an old body, optimizer, experience or random-stream position.

Compatibility checks cover algorithm, architecture, observation layout and
action order. Readers preserve legacy formats. Offline conversion verifies exact
expanded values and publishes only smaller files, retaining originals on failed
verification and refusing active recordings. Checkpoint, champion and replay
semantics are deliberately not interchangeable.

\subsubsection{Inspection and boundedness}
The viewer exposes run selection, seeking, birth/death/kill events, time-linked
species metrics, spatial groups, sampled action scores and current sight.
Observation/prediction panels retain their sample timestamp; current body/sight
can be newer. Gaps are not interpolated into evidence. A selected-agent score
history is capped at 64 samples, and population/food history is sampled to at
most 2,048 points plus the exact current point. Telemetry pages have a bounded,
file-stat-validated cache. Closed prediction histories defer chart creation.

These bounds do not make training constant-memory. Living agents retain private
models/buffers; frame size grows with population. Family ledgers, completed-run
summaries, artifact metadata and stored episodes also grow. Disk compression
reduces encoded size, not the size of expanded Python/JavaScript objects.
